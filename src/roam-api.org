* Overview

A Lisp bridge that lets Claude read and edit the =org-roam= slipbox.
Emacs and Claude exchange plists, never JSON or XML.

The bridge uses two libraries:
- The *Roam API* (=org-roam-node-list=, =org-roam-node-from-id=,
  =org-roam-backlinks-get=) for graph metadata and traversal.
- *org-ml* for body content, excerpts and every edit to a note.

Every public function takes positional arguments (IDs, strings,
predicates, org-ml nodes) and returns a plist or a list of plists,
except =sns-roam-rename-file=, which returns the new path. Every edit
to a note's first section goes through one write boundary,
=sns-roam--update-section=. Every failure the bridge detects raises a
condition under =sns-roam-error=, except the empty series name in
=sns-roam-meeting-note=, which is a =user-error= for the person at
=M-x=. No code path guesses.

This file tangles to =lisp/sns-roam-api.el=, which is committed, and
is loaded with =(require 'sns-roam-api)=. From the repository root,
tangle with =mise run tangle=, or:

#+begin_src sh :tangle no
emacs --batch --load org --eval '(org-babel-tangle-file "src/roam-api.org")'
#+end_src

* Errors

Every failure the bridge raises is a condition under =sns-roam-error=.
A caller tells one kind from another by its symbol, and reads the
facts as data, never from the message. A handler on =error= still
catches each one, because =sns-roam-error= is a child of =error=.
Two failures come from Emacs itself: =sns-roam-meeting-note= raises
=user-error= on an empty series name, and a missing =diff= program
raises =file-missing=.

** Contract

- *Data*: each condition's data is a plist that starts with =:kind=,
  the condition's symbol, then the facts. It has =:id= whenever the
  call had a node ID, except =sns-roam-diff-failure=, which the write
  boundary raises after the save, with =:file=. =(plist-get (cdr err) :kind)= gives the kind.
- *Message*: =error-message-string= prints the condition's message,
  which starts with =sns-roam: =, followed by the plist.
- *Facts*, by condition. A fact its declaration lists after
  =&optional= appears only when the site knows it.
  - =sns-roam-unknown-id=: =:id= alone.
  - =sns-roam-missing-file=: =:id= and =:path=, the file the database
    holds. The note moved and the database has not been synced since.
  - =sns-roam-malformed-note=: =:missing=, one of =section=,
    =property-drawer= or =roam-filename=, and =:file=. A missing drawer
    adds the =:key= being set, and a bad file name adds its =:name=.
  - =sns-roam-no-excerpt-container=: =:id=, =:point= and =:file=.
  - =sns-roam-match-count=: =:count= and =:operation=, and =:anchor=
    for a history line whose text appears twice.
  - =sns-roam-unsupported-element=: =:type= and =:operation=, and
    =:title= for a headline.
  - =sns-roam-history-layout=: =:reason=, one of =no-paragraphs=,
    =not-one-run= or =not-newest-first=, and =:dates= for the two dates
    out of order.
  - =sns-roam-bad-date=: =:date=.
  - =sns-roam-reparse-mismatch=: =:planned= and =:actual=, the
    type-and-text lists the check compares, and =:file=.
  - =sns-roam-file-exists=: =:id= and =:path=. Its declaration also
    allows =:slug=, for a new name that is the file's own, but the
    check that a file has the new name raises first.
  - =sns-roam-id-conflict=: =:id=, =:registered= and =:path=.
  - =sns-roam-index-failure=: =:id=, =:expected= and =:actual=.
  - =sns-roam-diff-failure=: =:status=, =:output= and =:file=. The
    section "Show what an edit changed" declares it.
- *Context*: a pure calculation raises the facts it holds. The public
  function that called it adds what it knows and the calculation does
  not, through =sns-roam--call-with-context=. The write boundary adds
  =:id=, =:file= and =:operation=, the public function's symbol.

** Declaring a kind

Each kind is declared once, with =sns-roam-define-error=, which takes
KIND, a symbol, MESSAGE, a string, and FIELDS, an argument list. It
defines the condition =sns-roam-KIND= and the function
=sns-roam--signal-KIND=, and raises nothing itself. A site raises the
condition by calling =sns-roam--signal-KIND= with the field values,
so the byte compiler warns when a call passes the wrong number of
facts. A field after =&optional= is left out of the data when its
value is nil. Fields are the facts the site knows, and
=sns-roam--call-with-context= adds the rest. =sns-roam--error-kinds=
lists every declared kind, and a test fails when no test raises one
of them.

** Implementation

#+begin_src emacs-lisp
(define-error 'sns-roam-error "sns-roam: error")

(defvar sns-roam--error-kinds nil
  "Every condition `sns-roam-define-error' has declared, oldest first.")

(defmacro sns-roam-define-error (kind message fields)
  "Declare the failure KIND, a child of `sns-roam-error', with MESSAGE and FIELDS.
Defines the condition `sns-roam-KIND', whose message is MESSAGE after
\"sns-roam: \", and the function `sns-roam--signal-KIND', whose argument
list is FIELDS.  The function signals the condition with the plist
:kind, then each field under its keyword; a field after `&optional'
is left out when its value is nil.  KIND joins `sns-roam--error-kinds'."
  (declare (indent 2))
  (let* ((condition (intern (format "sns-roam-%s" kind)))
         (signaller (intern (format "sns-roam--signal-%s" kind)))
         (required (seq-take-while (lambda (field) (not (eq field '&optional)))
                                   fields))
         (optional (cdr (memq '&optional fields)))
         (keyword (lambda (field) (intern (format ":%s" field)))))
    `(progn
       (define-error ',condition ,(concat "sns-roam: " message) 'sns-roam-error)
       (defun ,signaller ,fields
         ,(format "Signal `%s' with the facts\n%s.\nDeclared by `sns-roam-define-error'."
                  condition (upcase (format "%s" fields)))
         (signal ',condition
                 (append (list :kind ',condition
                               ,@(mapcan (lambda (field)
                                           (list (funcall keyword field) field))
                                         required))
                         ,@(mapcar (lambda (field)
                                     `(and ,field (list ,(funcall keyword field) ,field)))
                                   optional))))
       (add-to-list 'sns-roam--error-kinds ',condition t))))

(sns-roam-define-error unknown-id "no roam node has this id"
  (id))
(sns-roam-define-error missing-file
    "the note's file is not where the database says; run M-x org-roam-db-sync"
  (id path))
(sns-roam-define-error malformed-note "the note lacks a part a roam file has"
  (missing &optional id file key name))
(sns-roam-define-error no-excerpt-container
    "no paragraph, item, quote or verse block encloses the point"
  (id point file))
(sns-roam-define-error match-count "the match is not exactly one element"
  (count &optional operation anchor))
(sns-roam-define-error unsupported-element
    "the operation does not take this element type"
  (type &optional operation title))
(sns-roam-define-error history-layout
    "the note is not in the reference-note history layout"
  (reason &optional dates))
(sns-roam-define-error bad-date "the date is not written YYYY-MM-DD"
  (date))
(sns-roam-define-error reparse-mismatch
    "the edit would not read back as planned, so nothing was written"
  (planned actual &optional file))
(sns-roam-define-error file-exists "refusing to overwrite an existing file"
  (id path &optional slug))
(sns-roam-define-error id-conflict "the id already names another file"
  (id registered path))
(sns-roam-define-error index-failure
    "after indexing, the id does not resolve to the new file"
  (id expected actual))

(defun sns-roam--add-context (data context)
  "Return condition DATA with each key of plist CONTEXT that DATA lacks.
The added keys go straight after :kind, in CONTEXT's order, so DATA
still starts with :kind and a value DATA already holds wins.  Pure."
  (let ((missing (cl-loop for (key value) on context by #'cddr
                          unless (plist-member data key)
                          append (list key value))))
    (append (seq-take data 2) missing (seq-drop data 2))))

(defun sns-roam--call-with-context (context thunk)
  "Call THUNK and return its value, adding CONTEXT to any `sns-roam-error'.
CONTEXT is a plist of what the caller knows and THUNK's calculations
do not, such as the node ID.  The condition is signalled again, with
the same symbol, as `sns-roam--add-context' extends its data.  Other
errors pass through unchanged."
  (condition-case err
      (funcall thunk)
    (sns-roam-error
     (signal (car err) (sns-roam--add-context (cdr err) context)))))
#+end_src

* Seed: find by metadata

The first step of the read pipeline, and the cheapest. It filters
=org-roam-node-list= by a substring of a title, an alias or a tag,
and returns one plist per matching node.

** Contract

- *Input*: QUERY, a string matched as a case-insensitive substring.
- *Output*: a list of plists =(:id :title :file :tags :aliases)=, one
  per node. A node with several aliases still appears once. The list
  is empty when nothing matches. A node with no tags or aliases has
  nil under that key.
- *Errors*: none.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--node-to-plist (node)
  "Convert an `org-roam-node' NODE into a plist for Claude."
  (list :id       (org-roam-node-id node)
        :title    (org-roam-node-title node)
        :file     (org-roam-node-file node)
        :tags     (org-roam-node-tags node)
        :aliases  (org-roam-node-aliases node)))

(defun sns-roam-find-by-metadata (query)
  "Return roam nodes whose title, alias, or tag matches QUERY (substring, case-insensitive).

Each result is a plist of the shape
  (:id ID :title TITLE :file FILE :tags TAGS :aliases ALIASES).
QUERY is a string. Empty list on no match.

Deduped by :id — `org-roam-node-list' returns one entry per
(node, alias) pair, so a node with N aliases would otherwise
appear N+1 times."
  (let ((q (downcase query))
        (seen (make-hash-table :test 'equal))
        (results nil))
    (dolist (node (org-roam-node-list))
      (let* ((id      (org-roam-node-id node))
             (title   (or (org-roam-node-title node) ""))
             (aliases (org-roam-node-aliases node))
             (tags    (org-roam-node-tags node)))
        (when (and (not (gethash id seen))
                   (or (cl-search q (downcase title))
                       (cl-some (lambda (a) (cl-search q (downcase a))) aliases)
                       (cl-some (lambda (tg) (cl-search q (downcase tg))) tags)))
          (puthash id t seen)
          (push (sns-roam--node-to-plist node) results))))
    (nreverse results)))
#+end_src

** Discipline notes

- *Plist returns, always.* No =org-roam-node= struct crosses the API
  boundary. Claude reads plists only.
- *Provenance in every result.* =:id= and =:file= come with every
  result, so excerpts and citations need no further lookup.
- *No truncation.* The call returns every match. A cap that drops
  results without saying so is forbidden.

* Read: search note bodies

A case-insensitive substring search over the body text of every
=.org= file under =org-roam-directory=. It seeds a search when the
phrase is in no node's title, alias or tag. The read pipeline runs in
four steps:

  1. Seed by metadata (=find-by-metadata=).
  2. *Seed by body* (this function).
  3. Expand into the graph (=expand=).
  4. Mine excerpts (=excerpt=).

** Contract

- *Input*: QUERY, a string matched as a case-insensitive substring.
- *Output*: a flat list of hit plists, one per match, so a file with
  three matches gives three hits. Each hit holds:
  - =:id=: the roam node UUID of the file, read with =org-id-get= at
    point 1.
  - =:title=: the node's title from the roam database, or nil when the
    database lacks the ID.
  - =:file=: the file searched.
  - =:line=: the line number, counted from 1.
  - =:point=: the buffer position of the match, for =goto-char=.
  - =:hit-text=: the line that holds the match, trimmed.
  The list is empty when nothing matches.
- *Skipped*: a file with no =:ID:= at its top is not a roam node and
  gives no hits. Text up to and including the first =#+title:= line is
  not searched, so a search for a string like a UUID does not return
  every node.
- *Errors*: none.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--skip-header ()
  "Move point past the file's =:PROPERTIES:= drawer and =#+title:= line.
Stays at point 1 if no header found. Cheap heuristic: search
forward for =#+title:=, move to the line after; otherwise leave
point at the start of buffer."
  (goto-char (point-min))
  (when (re-search-forward "^#\\+title:.*\n" nil t)
    (goto-char (match-end 0))))

(defun sns-roam--search-file (file query)
  "Return a list of hit plists for QUERY in FILE.
Empty list if no hits or file isn't a roam node."
  (let ((re (regexp-quote query))
        (case-fold-search t)
        (hits nil))
    (with-temp-buffer
      (insert-file-contents file)
      (let ((id (org-with-point-at 1 (org-id-get))))
        (when id
          (let* ((node (org-roam-node-from-id id))
                 (title (when node (org-roam-node-title node))))
            (sns-roam--skip-header)
            (while (re-search-forward re nil t)
              (let* ((point (match-beginning 0))
                     (line  (line-number-at-pos point))
                     (line-text
                      (string-trim
                       (buffer-substring-no-properties
                        (line-beginning-position)
                        (line-end-position)))))
                (push (list :id id
                            :title title
                            :file file
                            :line line
                            :point point
                            :hit-text line-text)
                      hits)))))))
    (nreverse hits)))

(defun sns-roam-body-search (query)
  "Return all body-text matches for QUERY across the roam slipbox.

Each result is a plist of the shape
  (:id ID :title TITLE :file FILE :line LINE :point POINT :hit-text TEXT).

Substring match, case-insensitive. The =:PROPERTIES:= drawer
and =#+title:= line are skipped so UUID/keyword noise doesn't
match. Files without an =:ID:= property drawer (i.e. not a roam
node) are skipped silently. Empty list on no match."
  (let ((files (directory-files-recursively
                org-roam-directory "\\.org\\'")))
    (cl-mapcan (lambda (f) (sns-roam--search-file f query)) files)))
#+end_src

* Read: expand a node (one-hop subgraph)

Given a roam node ID, return the nodes one hop away, through incoming
links (backlinks) and outgoing links (forward links). The result is a
subgraph plist =(:nodes (...) :edges (...))=, never a flat list.

Backlinks come from =org-roam-backlinks-get=, because roam indexes
them. Roam does not index forward links, so the call walks the file's
org-ml AST for them and never greps the text. Only =id:= links count
as edges. A fuzzy =[[X]]= link names no node, so it is not part of
the graph.

** Contract

- *Input*: ID, a roam node UUID.
- *Output*: =(:nodes NODES :edges EDGES)=.
  - =:nodes=: the centre node first, then the node at the other end of
    each edge, once per distinct =:id=, each as =find-by-metadata=
    returns it. A note that links to itself therefore appears twice. A link target the database lacks appears with its =:id= and
    nil under every other key.
  - =:edges=: one plist per link, with =:source-id=, =:target-id=,
    =:direction= (=:backward= or =:forward=), =:point= and =:context=.
    A backlink's =:point= is its position in the source file and its
    =:context= is its outline path. A forward link's =:point= is its
    position in the centre's file and its =:context= is the plain text
    its description starts with, or nil when the description is empty
    or starts with markup.
- *Errors*: =sns-roam-unknown-id= when ID names no node, and
  =sns-roam-missing-file= when the centre's file has moved since the
  last sync.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--backlink-edges (target-node)
  "Return a list of backlink edge plists pointing at TARGET-NODE."
  (mapcar
   (lambda (bl)
     (let ((source (org-roam-backlink-source-node bl)))
       (list :source-id  (org-roam-node-id source)
             :target-id  (org-roam-node-id target-node)
             :direction  :backward
             :point      (org-roam-backlink-point bl)
             :context    (plist-get (org-roam-backlink-properties bl)
                                    :outline))))
   (org-roam-backlinks-get target-node)))

(defun sns-roam--forward-link-edges (source-node)
  "Return a list of forward-link edge plists from SOURCE-NODE.
Only =id:= links count; fuzzy and external links are skipped.
Loud failure if SOURCE-NODE's file has moved since the last sync."
  (let* ((file   (sns-roam--existing-file-or-error
                  (org-roam-node-id source-node)
                  (org-roam-node-file source-node)))
         (parsed (with-temp-buffer
                   (insert-file-contents file)
                   (org-mode)
                   (org-ml-parse-this-buffer)))
         (links  (org-ml-match '(:any * link) parsed)))
    (cl-loop for link in links
             when (string= (org-ml-get-property :type link) "id")
             collect
             (let* ((target-id (org-ml-get-property :path link))
                    (children (org-ml-get-children link))
                    (text-raw (and (stringp (car-safe children))
                                   (car children)))
                    (text (and text-raw (substring-no-properties text-raw))))
               (list :source-id  (org-roam-node-id source-node)
                     :target-id  target-id
                     :direction  :forward
                     :point      (org-ml-get-property :begin link)
                     :context    text)))))

(defun sns-roam-expand (id)
  "Return the one-hop subgraph around roam node ID.

Result shape:
  (:nodes (PLIST ...)
   :edges (PLIST ...))

=:nodes= contains every source/target node touched by an edge,
deduped by =:id=, plus the centre node itself. =:edges= contains
all backlinks (=:direction :backward=) and forward links
(=:direction :forward=) as edge plists.

Loud failure if ID has no roam node."
  (let* ((centre (org-roam-node-from-id id))
         (_ (unless centre
              (sns-roam--signal-unknown-id id)))
         (back-edges (sns-roam--backlink-edges centre))
         (fwd-edges  (sns-roam--forward-link-edges centre))
         (all-edges  (append back-edges fwd-edges))
         (other-ids  (delete-dups
                      (append (mapcar (lambda (e) (plist-get e :source-id)) back-edges)
                              (mapcar (lambda (e) (plist-get e :target-id)) fwd-edges))))
         (other-nodes (mapcar
                       (lambda (oid)
                         (let ((n (org-roam-node-from-id oid)))
                           (if n
                               (sns-roam--node-to-plist n)
                             ;; unresolved id — surface a stub
                             (list :id oid :title nil :file nil
                                   :tags nil :aliases nil))))
                       other-ids))
         (centre-plist (sns-roam--node-to-plist centre)))
    (list :nodes (cons centre-plist other-nodes)
          :edges all-edges)))
#+end_src

* Read: excerpt the element enclosing a point

Given a roam node ID and a buffer position =POINT= in its file, return
the smallest excerpt container that encloses the position, with the
headlines above it. It is the last step of the read pipeline:

  1. Seed by metadata (=find-by-metadata=).
  2. Seed by body (=body-search=), which gives hit plists with =:point=.
  3. Expand into the graph (=expand=).
  4. *Mine excerpts* (this function): turn a =:point= into the
     paragraph around it and its outline path.
  5. Synthesise, which Claude does.

The call reads the file into a temporary buffer and changes nothing.

** Contract

- *Input*:
  - =ID= (string): the roam node UUID.
  - =POINT= (integer): a buffer position in the node's file.
- *Output*: plist =(:id :file :point :text :container-type :outline)=.
  - =:text=: the printed excerpt container, trimmed. A container is a
    paragraph, an item, a quote block or a verse block.
  - =:container-type=: the symbol for the container's element type,
    so a caller can filter, for example to quotes.
  - =:outline=: a list of headline plists from root to leaf, each
    =(:level :raw-value :tags :todo-keyword)=. It is empty when POINT
    is in the section before the first headline.
- *Errors*: =sns-roam-unknown-id= and =sns-roam-missing-file= for ID.
  =sns-roam-no-excerpt-container= when no container encloses POINT.
  Then POINT is on a headline line, in a property drawer or somewhere
  else no excerpt comes from, and whatever produced POINT has a bug.

** Implementation

The walk visits the AST in pre-order and collects every element
whose =[:begin, :end)= window contains POINT. The result is the
ancestry chain from root to leaf, in the order of the recursion.
=:outline= and the container are both filters over that chain.

The container types exclude =plain-list=, because a list's =item=
children make better excerpts. A POINT in a bullet gets that bullet's
text, not the text of its list.

#+begin_src emacs-lisp
(defconst sns-roam--excerpt-container-types
  '(paragraph item quote-block verse-block)
  "Element types that count as excerpt containers for mining.
Walks descend past =plain-list= to its =item= children — the item
is the better excerpt unit than the whole list.")

(defun sns-roam--element-contains-point-p (element point)
  "Return non-nil if POINT lies within ELEMENT's [:begin, :end) window."
  (let ((b (org-ml-get-property :begin element))
        (e (org-ml-get-property :end element)))
    (and b e (<= b point) (< point e))))

(defun sns-roam--ancestry-at-point (root point)
  "Return the ancestry chain of elements containing POINT under ROOT.
Result is root-to-leaf, including ROOT when it contains POINT.
Each element appears once. Pure: no buffer state, no mutation."
  (when (sns-roam--element-contains-point-p root point)
    (cons root
          (cl-loop for child in (org-ml-get-children root)
                   for sub = (and (listp child)
                                  (sns-roam--ancestry-at-point child point))
                   when sub return sub))))

(defun sns-roam--headline-to-plist (h)
  "Convert headline AST node H into a plist for Claude."
  (list :level         (org-ml-get-property :level h)
        :raw-value     (org-ml-get-property :raw-value h)
        :tags          (org-ml-get-property :tags h)
        :todo-keyword  (org-ml-get-property :todo-keyword h)))

(defun sns-roam-excerpt (id point)
  "Return the excerpt container enclosing POINT in roam node ID's file.

Result shape:
  (:id ID
   :file FILE
   :point POINT
   :text TEXT
   :container-type SYMBOL
   :outline (HEADLINE-PLIST ...))

Loud failure if ID is unknown or POINT has no enclosing excerpt
container (=paragraph= / =item= / =quote-block= / =verse-block=).
The latter usually means POINT landed in a headline title line or
a property drawer — fix the upstream caller."
  (let* ((file    (sns-roam--node-file-or-error id))
         (root    (with-temp-buffer
                    (insert-file-contents file)
                    (org-mode)
                    (org-ml-parse-this-buffer)))
         (chain   (sns-roam--ancestry-at-point root point))
         (outline (cl-loop for el in chain
                           when (org-ml-is-type 'headline el)
                           collect (sns-roam--headline-to-plist el)))
         (container
          (cl-loop for el in (reverse chain)
                   when (memq (org-ml-get-type el)
                              sns-roam--excerpt-container-types)
                   return el)))
    (unless container
      (sns-roam--signal-no-excerpt-container id point file))
    (list :id              id
          :file            file
          :point           point
          :text            (string-trim (org-ml-to-string container))
          :container-type  (org-ml-get-type container)
          :outline         outline)))
#+end_src

** Discipline notes

- *One walk, two filters.* =sns-roam--ancestry-at-point= builds the
  chain from root to leaf, and =:outline= and the container both
  filter that one result, so the outline and the container always
  come from the same chain.
- *Loud failure when POINT has no container.* A property drawer or a
  headline line means the =:point= was built wrong, for example by a
  body search that matched where it should not. Raising shows the bug,
  where nil would hide it.
- *=plain-list= is not a container.* A search for text in a bullet
  wants the bullet, not its list. Items nest cleanly and lists do not.
- *Container types as data.* =sns-roam--excerpt-container-types= is a
  constant, not a chain of tests, so a type joins the list without a
  change to the walk.

* Mutate: set a file-level property

Set or update one property in the top-level =:PROPERTIES:= drawer of
a roam node's file. It adds metadata such as =:KIND:= or =:CREATED:=
to existing notes.

** Contract

- *Input*:
  - =ID= (string): the roam node UUID, found with
    =org-roam-node-from-id=.
  - =KEY= (string): the property name without colons, such as =KIND=,
    not =:KIND:=.
  - =VALUE= (string): the property value.
- *Output*: =(:id :file :diff)=, with =:diff= as "Show what an edit
  changed" describes.
- *Side effect*: saves the file. Setting a property to the value it
  has leaves the file as it was, and =:diff= is =""=, unless the
  buffer holds edits the owner has not saved. The save writes those
  too, and =:diff= shows them.
- *Errors*: those of the write boundary, =sns-roam--update-section=,
  and =sns-roam-malformed-note= with =:missing property-drawer= and
  =:key= when the first section has no drawer.
- *Discipline*: one node, one property, one call. No batching and no
  fuzzy match. The caller resolves the ID first.

** Implementation

The call parses the file's first =section= with =org-ml=, finds its
=property-drawer= and sets the requested =node-property=. The write
goes through =sns-roam--update-section=, so the drawer is the only
element written. The file is never edited as text.

** Discipline notes

- *Loud failure on an unknown ID.* No silent skip and no new node. A
  UUID that resolves to nothing is a bug in the caller, and the error
  shows it.
- *No drawer is built.* If a roam file lacks a property drawer, the
  call raises and adds none, so the error shows whatever left the file
  without one.
- *Idempotent.* Setting =:KIND:= to =permanent= twice leaves the file

  writes them.
- *One property per call.* Updates to several properties take several
  calls.

* Mutate: replace the body of a node

Replace the paragraphs and other body elements that come before
the first heading with new content. Property drawers, standalone
=#+= keywords (=#+title:=, =#+filetags:=) and every existing
heading with its content stay as they are. Affiliated keywords
(=#+name:=, =#+caption:=) belong to the element below them and are
removed with it. To change a heading, edit it by hand.

It turns a fleeting capture into an atomic permanent note. To change
one element and leave the rest, use =sns-roam-replace-element= or
=sns-roam-insert-element=.

** Contract

- *Input*:
  - =ID= (string): the roam node UUID.
  - =NEW-BODY= (string): the new body as org prose, possibly empty. It
    holds neither the property drawer nor the =#+title:= line, which
    stay as they are.
- *Output*: =(:id :file :diff)=, with =:diff= the =diff -u= of the file
  before and after, as "Show what an edit changed" describes.
- *Side effect*: saves the file.
- *Errors*: those of the write boundary, =sns-roam--update-section=.
- *Discipline*: replaces the body elements before the first heading.
  It never merges or appends. To add to that content, read it first,
  join the new text to it, and call this with the result.

** Implementation

Body edits are pure transforms over the note's =section= AST, handed
to one write boundary. Three layers:

1. =sns-roam--map-children=: a pure =(section -> section)= that
   applies a function to the section's full child list. It filters
   the list to keep children and appends to add them, and never
   slices parsed nodes into sublists. No I/O.
2. =sns-roam--update-section=: the one effect boundary every edit of
   the first section goes through. Its contract follows.
3. =sns-roam-set-body= and the other edit primitives: each passes a
   pure transform through the boundary.

=set-body= takes a string, because callers pass prose, not AST. It
parses the prose into body elements, and those replace the existing
body. The drawer and =#+title:= are never touched.

The write boundary, =sns-roam--update-section=, keeps this contract:

- *Input*: OPERATION, the symbol of the public function that called,
  such as =sns-roam-insert-element=. ID, the roam node UUID.
  SECTION-FN, a pure function from the note's first section to the
  new section.
- *Output*: =(:id :file :diff)=. =:diff= is the =diff -u= of the file
  as it was on disk before the call and as the save left it, or =""=
  when the file did not change.
- *Side effects*: visits the file with =find-file-noselect=, edits the
  buffer and saves it. It writes only the children whose text
  changed, as "Write only what changed" describes. Every child
  SECTION-FN left alone, and every headline after the section, keeps
  the text the owner typed. The save also writes edits the owner had
  not saved, so the diff shows them too.
- *Narrowing*: the edit parses and changes all of a note the owner
  has narrowed. Afterwards the narrowing covers the same text, grown
  or shrunk only by what the edit changed inside it. A refused edit
  leaves the narrowing as it was.
- *Errors*: =sns-roam-unknown-id= and =sns-roam-missing-file= before
  any buffer is visited. Then, before anything is written:
  - =sns-roam-malformed-note= with =:missing section= when the note
    has no first section.
  - Any =sns-roam-error= SECTION-FN raises. Other errors pass through
    unchanged, without the keys below.
  - =sns-roam-unsupported-element= when org prints a kept element as
    other text once its blank lines change.
  - =sns-roam-reparse-mismatch= when the edits would not read back as
    planned.
  Each of these gains =:id=, =:file= and =:operation=, and the buffer
  is left as it was. After the save, =sns-roam-diff-failure= when
  =diff= fails.

(defun sns-roam--section-header-p (element)
  "Non-nil if ELEMENT is roam header furniture (property-drawer or keyword)."
  (or (org-ml-is-type 'property-drawer element)
      (org-ml-is-type 'keyword element)))

(defun sns-roam--map-children (fn section)
  "Return SECTION with FN applied to its full child list.
FN takes the section's children (header furniture + body) and
returns a new child list. Pure: returns a new section, mutates
nothing.

IMPORTANT: operate on the child list as a whole. Do NOT slice it
into header/body sublists and re-`append` them. Parsed nodes carry
buffer positions and :parent backrefs; reassembling sliced sublists
of parsed nodes corrupts those, and the write in
`sns-roam--update-section' finds unchanged children by those
positions. Filtering the list in place (e.g. `seq-filter`) is safe;
slicing-and-rejoining is not.

Body helpers are expressed in terms of this:
- append: `(append children NEW)` — header stays in front untouched.
- replace-body: `(append (seq-filter #'sns-roam--section-header-p
  children) NEW-BODY)` — keep header, drop old body, add new."
  (org-ml-map-children fn section))

(defun sns-roam--parse-body-elements (string)
  "Parse STRING of org prose into a list of body elements.
A bare string parses to a single headline-less section; we return
that section's children. Empty STRING yields nil."
  (if (string-empty-p string)
      nil
    (let* ((tree    (with-temp-buffer
                      (insert string)
                      (org-ml-parse-this-buffer)))
           (section (car (org-ml-get-children tree))))
      (if section (org-ml-get-children section) nil))))

(defun sns-roam--edit-section (id file section-fn)
  "Apply pure SECTION-FN to the first section of the current buffer.
Parses the buffer as it is narrowed, so the caller widens it first.
Raises before anything is written when the note of ID in FILE has no
first section, when SECTION-FN raises, or when the edits would not
read back as planned.  Returns what `sns-roam--apply-edits' returns."
  (let ((section (car (org-ml-get-children (org-ml-parse-this-buffer)))))
    (unless (and section (org-ml-is-type 'section section))
      (sns-roam--signal-malformed-note 'section id file))
    (let* ((new-section (funcall section-fn section))
           (edits       (sns-roam--section-edits
                         (org-ml-get-children section)
                         (org-ml-get-children new-section))))
      (sns-roam--check-edits edits new-section file)
      (sns-roam--apply-edits edits))))

(defun sns-roam--update-section (operation id section-fn)
  "Apply pure SECTION-FN (section -> section) to node ID and save.
The single write boundary for every mutation of the note's first
section.  It parses the buffer, applies SECTION-FN, and writes only
the children whose text changed, as `sns-roam--section-edits'
decides.  Every child SECTION-FN left alone, and every headline after
the section, keeps the text the owner typed.  SECTION-FN raises
before anything is written, so a refusal leaves the buffer as it was.
OPERATION is the symbol of the public function that called, such as
`sns-roam-insert-element'.  An `sns-roam-error' raised while the
section is planned and checked gains :id, :file and :operation.
Loud failure on unknown ID or malformed file.  Returns (:id :file
:diff), where :diff is `sns-roam--file-diff' of the note's file as
it was on disk before the call and as the save left it, \"\" when the
file did not change.  The save also writes edits the owner had not yet
saved in the buffer, so the diff shows them too."
  (let ((file (sns-roam--node-file-or-error id)))
    (with-current-buffer (find-file-noselect file)
      ;; The file on disk, not the buffer: the save below also writes any
      ;; edits the owner has not saved, and the diff must show them.
      (let ((before (with-temp-buffer
                      (insert-file-contents file)
                      (buffer-string))))
        (sns-roam--call-with-context
         (list :id id :file file :operation operation)
         (lambda ()
           ;; The owner may have narrowed the note in Emacs.  Parse and
           ;; edit all of it.  After a refusal, `save-restriction' gives
           ;; their narrowing back.  After an edit, the narrowing comes
           ;; from `sns-roam--narrowing-after'.  A marker cannot tell an
           ;; edit that ends where the narrowing starts from one that
           ;; starts there.
           (let* ((narrowing    (when (buffer-narrowed-p)
                                  (cons (point-min) (point-max))))
                  (replacements (save-restriction
                                  (widen)
                                  (sns-roam--edit-section id file section-fn))))
             (when narrowing
               (let ((bounds (sns-roam--narrowing-after narrowing replacements)))
                 (narrow-to-region (car bounds) (cdr bounds)))))))
        (save-buffer)
        (list :id id :file file
              :diff (sns-roam--file-diff file before (sns-roam--widened-text)))))))

(defun sns-roam--widened-text ()
  "Return all of the current buffer's text, ignoring any narrowing."
  (save-restriction
    (widen)
    (buffer-substring-no-properties (point-min) (point-max))))

(defun sns-roam-set-body (id new-body)
  "Replace the body of roam node ID with NEW-BODY.

The paragraphs and other body elements before the first heading
are replaced with NEW-BODY parsed as org prose. Property drawers,
standalone =#+= keywords (=#+title:=, =#+filetags:=) and every
existing heading with its content stay. Affiliated keywords
(=#+name:=, =#+caption:=) go with the element they precede.
NEW-BODY is a string; empty clears those body elements.
Returns (:id :file). Errors loudly on unknown ID or malformed file."
  (sns-roam--update-section
   'sns-roam-set-body id
   (lambda (section)
     (sns-roam--map-children
      (lambda (children)
        (append (seq-filter #'sns-roam--section-header-p children)
                (sns-roam--parse-body-elements new-body)))
      section))))

** Discipline notes

- *Pure transform, one effect boundary.* The body operation is a
  pure =(section -> section)=, and the only I/O is in
  =sns-roam--update-section=. Every body primitive composes the same
  way, so the module composes transforms and has no procedures that
  edit the buffer directly.
- *Header kept by structure, not by position.* The transform keeps
  the header furniture with =seq-filter= and appends the new body
  after it, with no cursor positions or =delete-region=. It works on
  the full child list and never slices parsed nodes into sublists, as
  the warning on =sns-roam--map-children= explains.
- *An empty body is valid.* =""= parses to nil, which gives an empty
  body.

* Write only what changed

An edit through the API changes only the elements it was asked to
change. A table typed as =|a|b|=, a list item typed as =+  item one=
and a table under an untouched headline all keep their text. Org
prints each of them in another form.

** Contract

- *Input*: the parsed children of the note's first section, and the
  children a section transform returned.
- *Output*: a list of edits, each =(:begin B :end E :text TEXT)= or
  =(:blank-lines-end P :end E :text TEXT)=, last in the buffer first.
  The buffer text from B, or from where the blank lines ending at P
  begin, to E becomes TEXT.
- *Kept*: a new child is unchanged when a parsed child after the last
  kept one has the same =:begin= and the same =org-ml-to-string=
  text. Its typed text stays in the buffer and nothing is written
  there. A transform copies the children it leaves alone, and the
  copies keep the parse's =:begin= and =:end=.
- *Runs*: the children between two kept ones, or before the first or
  after the last, form a run. Its old children are removed and its
  new ones written, as one edit from the first old child's =:begin=
  to the last one's =:end=. A run with no old children inserts at the
  end of the kept child before it, or at the =:begin= of the first old
  child when no kept child comes before it.
- *Blank lines*: a new child that differs from its parsed child only
  in =:post-blank= is kept too. Its typed text stays, and only the
  blank lines after its last non-blank line change. The edit after it
  carries =:blank-lines-end E=, the child's =:end=, in place of
  =:begin=, because where those blank lines start is a buffer fact.
  Its text starts with the blank lines =org-ml-to-string= prints for
  the new =:post-blank=, followed by the run's text, if any.
- *Text*: the only text an edit carries is =org-ml-to-string= of new
  nodes, and its bounds are positions the parse gave. A child the
  transform changed in more than its blank lines, such as a drawer
  with a new property, is written in org's form.
- *Headlines*: the edits cover the first section only, so headlines
  after it are never written.
- *Errors*: =sns-roam-unsupported-element= with =:type= when org
  prints a kept element as other text once it has blank lines, so it
  cannot keep its typed text. =sns-roam-reparse-mismatch= when the
  edits, made on a copy of the buffer, would not read back as the new
  section.

** Implementation

=sns-roam--section-edits= is the calculation, from two child lists to
the edits, and needs no buffer. =sns-roam--apply-edits= is the only
code that changes the buffer. =sns-roam--edit-section= parses the
note, calls the transform, and passes the edits from one to the
other. =sns-roam--update-section= calls it with the buffer widened.

#+begin_src emacs-lisp
(defun sns-roam--kept-index (old-children start child)
  "Return the index in OLD-CHILDREN of the child CHILD leaves unchanged, or nil.
The match is at index START or later, has CHILD's :begin position,
and prints to the same `org-ml-to-string' text once CHILD's
:post-blank is set to the match's.  A child whose only change is its
blank lines is therefore kept, and `sns-roam--blank-lines-text' gives
the blank lines to write.  A built node has no :begin, so it never
matches.  Pure."
  (when-let* ((begin (org-ml-get-property :begin child)))
    (cl-position-if (lambda (old-child)
                      (and (eql begin (org-ml-get-property :begin old-child))
                           (string= (org-ml-to-string old-child)
                                    (org-ml-to-string
                                     (org-ml-set-property
                                      :post-blank
                                      (org-ml-get-property :post-blank old-child)
                                      child)))))
                    old-children
                    :start start)))

(defun sns-roam--blank-lines-text (old-child child)
  "Return the blank lines `org-ml-to-string' prints after CHILD, or nil.
Nil means CHILD has as many blank lines as OLD-CHILD, the parsed
child it keeps, so none are written.  Otherwise the text is what
`org-ml-to-string' prints for CHILD past what it prints for CHILD
with no blank lines.  Pure."
  (unless (eql (org-ml-get-property :post-blank old-child)
               (org-ml-get-property :post-blank child))
    (let ((printed (org-ml-to-string child))
          (content (org-ml-to-string (org-ml-set-property :post-blank 0 child))))
      ;; When org prints the element as other text once it has blank
      ;; lines, the element cannot keep its typed text.
      (unless (string-prefix-p content printed)
        (sns-roam--signal-unsupported-element (org-ml-get-type child)))
      (substring printed (length content)))))

(defun sns-roam--run-edit (old-children from to new-nodes blank-lines)
  "Return the edit that replaces OLD-CHILDREN from index FROM up to TO with NEW-NODES.
The edit is (:begin B :end E :text TEXT), where TEXT is the
`org-ml-to-string' text of NEW-NODES.  B is where the child at FROM
begins, or where the last child ends when FROM is past the end.  E is
where the child before TO ends, or B when the run removes no child.
A section's children follow each other with no text between them, so
these bounds cover exactly the removed children.
BLANK-LINES, when non-nil, are the new blank lines of the kept child
before FROM, which ends at B.  The edit then starts where that
child's blank lines start, a buffer fact, so it carries
:blank-lines-end B in place of :begin, and TEXT starts with
BLANK-LINES.  One edit covers both, so the blank lines and the run
are written in order at the same place.
Returns nil when the edit would remove and add nothing.  Pure."
  (when (or blank-lines (< from to) new-nodes)
    (let* ((begin (if (< from (length old-children))
                      (org-ml-get-property :begin (nth from old-children))
                    (org-ml-get-property :end (car (last old-children)))))
           (end   (if (< from to)
                      (org-ml-get-property :end (nth (1- to) old-children))
                    begin))
           (text  (mapconcat #'org-ml-to-string new-nodes "")))
      (if blank-lines
          (list :blank-lines-end begin :end end :text (concat blank-lines text))
        (list :begin begin :end end :text text)))))

(defun sns-roam--section-edits (old-children new-children)
  "Return the edits that turn the text of OLD-CHILDREN into NEW-CHILDREN.
OLD-CHILDREN are a section's parsed children; NEW-CHILDREN are the
children a transform returned for it.  Each new child that
`sns-roam--kept-index' finds unchanged keeps its typed text, apart
from blank lines it gains or loses.  Each run of other children
between two kept ones becomes one edit from `sns-roam--run-edit',
which also writes the new blank lines of the kept child before it.
The edits come last in the buffer first, so making them in order
leaves the positions of the rest as the parse gave them.  Pure."
  (let ((from 0)
        (pending-new-nodes nil)
        (blank-lines nil)
        (edits nil))
    (dolist (child new-children)
      (if-let* ((kept (sns-roam--kept-index old-children from child)))
          (progn
            (push (sns-roam--run-edit old-children from kept
                                      (reverse pending-new-nodes)
                                      blank-lines)
                  edits)
            (setq blank-lines (sns-roam--blank-lines-text
                               (nth kept old-children) child)
                  from (1+ kept)
                  pending-new-nodes nil))
        (push child pending-new-nodes)))
    (push (sns-roam--run-edit old-children from (length old-children)
                              (reverse pending-new-nodes)
                              blank-lines)
          edits)
    (delq nil edits)))

(defun sns-roam--blank-lines-begin (end)
  "Return where the blank lines that end at END begin in the current buffer.
That is the start of the line after the last one before END with a
non-blank character, or END when that line has no newline.  Trailing
spaces on that line stay where they are."
  (save-excursion
    (goto-char end)
    (skip-chars-backward " \t\n")
    (forward-line 1)
    (min end (point))))

(defun sns-roam--edit-begin (edit)
  "Return where EDIT starts in the current buffer.
That is its :begin, or for an edit with :blank-lines-end, where those
blank lines begin."
  (if-let* ((blank-lines-end (plist-get edit :blank-lines-end)))
      (sns-roam--blank-lines-begin blank-lines-end)
    (plist-get edit :begin)))

(defun sns-roam--apply-edits (edits)
  "Make EDITS from `sns-roam--section-edits' in the current buffer, in order.
Each edit replaces the text between `sns-roam--edit-begin' and its
:end with its :text.  EDITS come last in the buffer first, so each
one leaves the positions of those still to come as the parse gave
them.
A file need not end with a newline, so an edit that writes after a
last line without one starts a new line first; otherwise the new
text would join that line and change what it parses as.
Returns one (:begin B :end E :new-end N) per edit, in the order made:
the text from B to E became the text from B to N."
  (save-excursion
    (mapcar (lambda (edit)
              (let ((begin (sns-roam--edit-begin edit))
                    (end   (plist-get edit :end))
                    (text  (plist-get edit :text)))
                (delete-region begin end)
                (goto-char begin)
                (when (and (not (string-empty-p text))
                           (> begin (point-min))
                           (not (eq (char-before begin) ?\n)))
                  (insert "\n"))
                (insert text)
                (list :begin begin :end end :new-end (point))))
            edits)))

(defun sns-roam--narrowing-start-after (start replacement)
  "Return where a narrowing that began at START begins after REPLACEMENT.
A REPLACEMENT from `sns-roam--apply-edits' that ends at or before
START lies outside the narrowing, so START shifts by the change in
length.  One that starts at START or covers it is inside the
narrowing, which then begins where the new text does.  Pure."
  (let ((begin (plist-get replacement :begin))
        (end   (plist-get replacement :end)))
    (cond ((>= start end) (+ start (- (plist-get replacement :new-end) end)))
          ((> start begin) begin)
          (t start))))

(defun sns-roam--narrowing-end-after (narrowing-end replacement)
  "Return where a narrowing that ended at NARROWING-END ends after REPLACEMENT.
A REPLACEMENT from `sns-roam--apply-edits' that starts at or after
NARROWING-END lies outside the narrowing and leaves it.  One that
ends at or before NARROWING-END shifts it by the change in length.
One that covers it is inside the narrowing, which then ends where
the new text does.  Pure."
  (let ((begin   (plist-get replacement :begin))
        (end     (plist-get replacement :end))
        (new-end (plist-get replacement :new-end)))
    (cond ((<= narrowing-end begin) narrowing-end)
          ((>= narrowing-end end) (+ narrowing-end (- new-end end)))
          (t new-end))))

(defun sns-roam--narrowing-after (narrowing replacements)
  "Return NARROWING, a (START . END) cons, after REPLACEMENTS were made.
REPLACEMENTS are what `sns-roam--apply-edits' returned, in the order
it made them.  The narrowing covers the same text afterwards, grown
or shrunk only by what a replacement changed inside it.  Pure."
  (seq-reduce (lambda (bounds replacement)
                (cons (sns-roam--narrowing-start-after (car bounds) replacement)
                      (sns-roam--narrowing-end-after (cdr bounds) replacement)))
              replacements
              narrowing))

(defun sns-roam--child-signature (children)
  "Return the type and trimmed printed text of each of CHILDREN.  Pure."
  (mapcar (lambda (child)
            (list (org-ml-get-type child)
                  (org-ml-to-trimmed-string child)))
          children))

(defun sns-roam--check-edits (edits new-section file)
  "Raise unless making EDITS gives the current buffer NEW-SECTION's children.
Copies the buffer into a temporary one, makes EDITS there, and parses
the result.  The first section's children must match NEW-SECTION's
by type and trimmed text, or `sns-roam-reparse-mismatch' names FILE
and both lists, and the note's buffer is left as it was.  This catches any edit whose text
would read back as something else, such as two elements merged by a
missing line break."
  (let* ((text     (save-restriction
                     (widen)
                     (buffer-substring-no-properties (point-min) (point-max))))
         (reparsed (with-temp-buffer
                     (insert text)
                     (sns-roam--apply-edits edits)
                     (delay-mode-hooks (org-mode))
                     (let ((first (car (org-ml-get-children
                                        (org-ml-parse-this-buffer)))))
                       (when (org-ml-is-type 'section first)
                         (org-ml-get-children first))))))
    (let ((planned (sns-roam--child-signature (org-ml-get-children new-section)))
          (actual  (sns-roam--child-signature reparsed)))
      (unless (equal planned actual)
        (sns-roam--signal-reparse-mismatch planned actual file)))))
#+end_src

** Discipline notes

- *Unchanged by text and position.* A child is unchanged only when
  it sits where the parse put it and prints the same. The printed
  text of =|a|b|= and its copy are both =| a | b |=, so the copy is
  kept, and the buffer keeps =|a|b|=.
- *AST-based.* No step edits the note as raw text. The edits replace
  parsed children with printed nodes.
- *Checked before written.* =sns-roam--check-edits= makes the edits
  on a copy and parses it first. Every primitive gets the check, so an
  edit org would read back differently, for whatever reason, raises
  instead of changing the note.
- *A missing final newline.* A file may end without one. An edit
  written after such a last line starts a new line, which is the
  separator =org-ml-to-string= would print between the two elements.
- *Narrowed buffers.* An edit parses and changes all of a note the
  owner has narrowed, and leaves the narrowing on the same text,
  grown or shrunk only by what the edit changed inside it. A refused
  edit leaves the narrowing as it was.

* Show what an edit changed

Each primitive that edits an existing note returns =:diff=, a unified
diff of the note's file before and after the edit. An edit that loses
a line still returns success, and the diff shows the lost line at
once.

** Contract

- *Input*: the note's file name, and its widened text before and after
  the edit.
- *Output*: the output of =diff -u=, whose two headers both name the
  note's file. An edit that changes nothing gives =""=.
- *Errors*: a =diff= exit status other than 0 or 1 raises
  =sns-roam-diff-failure= with =:status=, =:output= and =:file=. A
  missing =diff= program raises Emacs's own =file-missing=.
- *Requires*: the system =diff=, which macOS and Linux have.

** Implementation

The texts go to two temporary files, because =diff= compares files.
=--label= replaces each temporary file's name with the note's in the
headers. The temporary files are deleted whether or not =diff= runs.

#+begin_src emacs-lisp
(sns-roam-define-error diff-failure "diff could not compare the note's text"
  (status output &optional file))

(defun sns-roam--diff-result (status output file)
  "Return the diff that `diff -u' printed as OUTPUT and exited with STATUS.
Status 0 means the texts are the same, so the diff is \"\".  Status 1
means they differ, so the diff is OUTPUT.  Any other status, or a
signal description string from `call-process', raises
`sns-roam-diff-failure' naming FILE.  Pure."
  (pcase status
    (0 "")
    (1 output)
    (_ (sns-roam--signal-diff-failure status output file))))

(defun sns-roam--file-diff (file before after)
  "Return a unified diff of BEFORE and AFTER, two texts of FILE.
Writes each text to a temporary file and runs the system `diff -u' on
them, labelled with FILE so the headers name the note.  Deletes the
temporary files afterwards.  See `sns-roam--diff-result' for what the
exit status gives."
  (let* ((coding-system-for-write 'utf-8-unix)
         (coding-system-for-read  'utf-8-unix)
         (before-file (make-temp-file "sns-roam-before-" nil ".org" before)))
    (unwind-protect
        (let ((after-file (make-temp-file "sns-roam-after-" nil ".org" after)))
          (unwind-protect
              (with-temp-buffer
                (let ((status (call-process "diff" nil t nil "-u"
                                            "--label" file "--label" file
                                            before-file after-file)))
                  (sns-roam--diff-result status (buffer-string) file)))
            (delete-file after-file)))
      (delete-file before-file))))
#+end_src

** Discipline notes

- *After the write.* The diff is made once the note is saved, from the
  buffer's widened text, so it shows what the file now holds. A refused
  edit raises before the write and returns no diff.
- *Not for new notes.* =sns-roam-create-node= has no file before, so it
  returns no =:diff=.

* Mutate: append a relationship link

Append a link from one note to another, which is how a Zettelkasten
connects two ideas. The link goes in a new body paragraph, a sentence
with an inline =[[id:...]]= link, so the connection carries its
reasoning. A link is a statement, not decoration.

The link goes one way. org-roam provides backlinks, so the reverse
direction is found without a second link.

** Contract

- *Input*:
  - =FROM-ID= (string): the note gaining the link.
  - =TO-ID= (string): the link target.
  - =LABEL= (string): the link's display text.
  - =BEFORE= (string): the prose before the link in the paragraph.
  - =AFTER= (string): the prose after the link, such as =". "=, a
    trailing clause or a full stop. It lets the link sit anywhere in
    a sentence with its punctuation right. Pass =""= for nothing after.
- *Output*: =(:from :to :file :diff)=, with =:diff= as the write
  boundary gives it.
- *Side effect*: appends one paragraph to FROM-ID's body and saves the
  file.
- *Errors*: =sns-roam-unknown-id= or =sns-roam-missing-file= for
  TO-ID, before anything else, then those of the write boundary for
  FROM-ID.
- *Discipline*: existing content keeps its text. Both endpoints are
  checked before the note changes. The primitive does not check
  whether the link exists already. That policy belongs to the skill
  that calls it, =roam-distill=, so the primitive makes one change
  only.

** Implementation

A pure body transform that appends one paragraph, passed through
=sns-roam--update-section=. The paragraph is built as an AST node and
added to the child list. No code edits the buffer directly.
=BEFORE= and =AFTER= surround the link, so the caller controls
phrasing and punctuation. Empty strings are dropped, so the paragraph
holds no empty text nodes. The paragraph goes after the section's
last child, spaced by =sns-roam--insert-beside=. That child keeps at
least one blank line, and the paragraph takes the blank lines the
child had. A link added above a headline therefore has as many blank
lines before the headline as the last child had, which may be none.

#+begin_src emacs-lisp
(defun sns-roam-append-link (from-id to-id label before after)
  "Append a relationship paragraph to FROM-ID linking to TO-ID.
The paragraph reads BEFORE then an inline [[id:TO-ID][LABEL]] link
then AFTER, and becomes the last body element, spaced as
`sns-roam--insert-beside' spaces an element placed after the last
child. Existing content is untouched. One-directional; org-roam
backlinks give the reverse.
The primitive does NOT dedupe — call it once per intended link.
Loud failure if FROM-ID or TO-ID is unknown. Returns (:from :to :file
:diff), :diff as `sns-roam--update-section' gives it."
  (sns-roam--node-file-or-error to-id)  ; validate target exists, loud
  (let* ((link  (org-ml-build-link (concat "id:" to-id) label))
         ;; Drop empty BEFORE/AFTER so no empty secondary-strings sneak in.
         (parts (seq-remove (lambda (x) (and (stringp x) (string-empty-p x)))
                            (list before link after)))
         (res (sns-roam--update-section
              'sns-roam-append-link from-id
              (lambda (section)
                (sns-roam--map-children
                 (lambda (children)
                   (sns-roam--insert-beside children
                                            (car (last children))
                                            (apply #'org-ml-build-paragraph parts)
                                            t))
                 section)))))
    (list :from from-id :to to-id
          :file (plist-get res :file)
          :diff (plist-get res :diff))))
#+end_src

** Discipline notes

- *Additive.* This appends and never rewrites an existing element.
  =sns-roam-replace-element= below replaces one element, and both
  compose through =sns-roam--update-section=.
- *One way.* Backlinks cover the reverse direction.

* Read: the body elements of a node

Return the body elements before a note's first heading, as parsed
org-ml nodes, so Claude can show the text an edit will replace. The
roam-distill skill calls this before =replace-element= or =set-body=.
Org decides where a paragraph ends, so a caller reads the elements
here and never splits the file on blank lines.

** Contract

- *Input*: =ID= (string), the roam node UUID.
- *Output*: plist =(:id ID :file FILE :elements NODES)=.
  - =:elements=: the section's children with the header furniture
    (property drawer, =#+= keywords) removed, in buffer order. Nil
    when the note has no body before its first heading, or when the
    file opens straight onto a heading.
- *Side effect*: none on disk. The file is visited with
  =find-file-noselect=, as =sns-roam--update-section= visits it, so a
  buffer the owner has open is parsed with its unsaved edits, and the
  text returned is the text the following edit acts on. Nothing is
  saved and the buffer's modified flag is left as it was. A note the
  owner has narrowed is read in full.
- *Errors*: =sns-roam-unknown-id= when ID names no node, and
  =sns-roam-missing-file= when its file has moved since the last sync.

** Implementation

The read mirrors the write boundary: same ID resolution, same buffer,
same header predicate. It filters the full child list, as the
warning on =sns-roam--map-children= asks.

#+begin_src emacs-lisp
(defun sns-roam-body-elements (id)
  "Return the body elements before the first heading of roam node ID.

Returns:
  (:id ID :file FILE :elements NODES)

NODES are the parsed org-ml children of the note's first section,
without the property drawer and `#+' keywords, in buffer order; nil
when there is no such body.  The note is parsed from the buffer
`find-file-noselect' returns, the one `sns-roam--update-section'
edits, so unsaved edits are included.  Writes nothing.  Errors
loudly on an unknown ID."
  (let ((file (sns-roam--node-file-or-error id)))
    (with-current-buffer (find-file-noselect file)
      ;; Read all of the note, even when the owner has narrowed it.
      (let ((first-child (car (org-ml-get-children
                               (save-restriction
                                 (widen)
                                 (org-ml-parse-this-buffer))))))
        (list :id       id
              :file     file
              :elements (when (org-ml-is-type 'section first-child)
                          (seq-remove #'sns-roam--section-header-p
                                      (org-ml-get-children first-child))))))))
#+end_src

** Discipline notes

- *Same buffer as the write.* Reading the file from disk would show
  the saved text while =update-section= edits the buffer, so the
  before text shown to the owner could differ from what the edit
  replaces.
- *Nodes, not strings.* The caller serialises with
  =org-ml-to-trimmed-string= where it shows them, and can build a
  =replace-element= predicate from the same nodes.

* Mutate: replace a body element

Replace one body element, such as a claim's paragraph or a stale
sentence, without writing out the rest of the body as =set-body=
needs. A predicate picks the element, and exactly one must match, so
an ambiguous edit never changes the wrong place.

** Contract

- *Input*:
  - =ID= (string): the roam node UUID.
  - =PRED= (function): a unary predicate on an org-ml node. It must
    match exactly one child of the note's first section.
  - =NEW-ELEMENT= (org-ml node): the replacement, built with
    =org-ml-build-*=.
- *Output*: =(:id :file :diff)=.
- *Side effect*: replaces the matched element in ID's body and saves
  the file.
- *Errors*: =sns-roam-match-count= with =:count= when PRED matches no
  element or several, and those of the write boundary. The file is
  unchanged after each of them except =sns-roam-diff-failure=, which
  comes after the save.
- *Discipline*: one match or an error, never a guess among several.
  AST in, AST out, with no string editing. It replaces an element
  entire and does not edit inside one.

** Implementation

A pure transform matches by predicate, checks that exactly one
element matched, and maps that match to NEW-ELEMENT. It passes
through =sns-roam--update-section=. The predicate runs over every
child of the section, the property drawer and keywords included,
though a predicate on content rarely matches them.

#+begin_src emacs-lisp
(defun sns-roam-replace-element (id pred new-element)
  "Replace the unique body element of node ID matching PRED with NEW-ELEMENT.
PRED is a unary predicate on an org-ml node; NEW-ELEMENT is a built
org-ml node. Asserts exactly one match — loud error on zero or many,
so an ambiguous edit never silently hits the wrong element. Composes
through `sns-roam--update-section'. Returns (:id :file)."
  (sns-roam--update-section
   'sns-roam-replace-element id
   (lambda (section)
     (let ((matches (org-ml-match `((:pred ,pred)) section)))
       (unless (= 1 (length matches))
         (sns-roam--signal-match-count (length matches)))
       (org-ml-match-map `((:pred ,pred))
                         (lambda (_old) new-element)
                         section)))))
#+end_src

** Discipline notes

- *One match, loud failure.* No match, or several, raises, so an edit
  to the wrong element cannot happen.
- *Element by element.* It replaces a matched element entire. To fix
  one word in a paragraph, build the new paragraph and replace the old
  one.

* Mutate: insert a body element next to another

Add one element beside an existing body element, and leave every
other element as it was. A history line in a reference note is the
usual case. =set-body= would make Claude write out every paragraph
for a one-element change. A rewritten paragraph can lose a line.

** Contract

- *Input*:
  - =ID= (string): the roam node UUID.
  - =PRED= (function): a unary predicate on an org-ml node. It sees
    only body elements, never the property drawer or =#+= keywords.
    It must match *exactly one*.
  - =NEW-ELEMENT= (org-ml paragraph): the element to add, built via
    =org-ml-build-paragraph=. Anything else is refused, because a list
    beside a list would merge. Its =:post-blank= is set by the call.
  - =AFTER= (optional): non-nil inserts after the anchor; nil
    inserts before it.
- *Output*: =(:id :file :diff)=, as the write boundary returns it.
- *Side effect*: adds NEW-ELEMENT to the body of ID's file and saves
  it.
- *Spacing*: no gap shrinks, because org ends some elements, such as
  footnote definitions, only at two blank lines. The element in front
  of the new paragraph keeps its trailing blank lines, at least one,
  unless it is header furniture, which is left as it was. The new
  paragraph has one blank line after it when a body element
  follows, and otherwise the anchor's old trailing lines, so none
  appears before a first headline that had none.
- *Reparse check*: before anything is written, the planned section is
  printed and parsed again. Its body elements must match the planned
  ones by type and trimmed text.
- *Errors*: each is raised before anything is written, so the file is
  unchanged, except =sns-roam-diff-failure=, which comes after the save.
  - =sns-roam-unsupported-element= with =:type= and
    =:operation sns-roam-insert-element= when NEW-ELEMENT is not a
    paragraph.
  - =sns-roam-match-count= with =:count= and
    =:operation sns-roam-insert-element= when PRED matches no body
    element or several.
  - =sns-roam-reparse-mismatch= with =:planned=, =:actual= and =:file=
    when the planned section fails the reparse check.
  - Those of the write boundary, with the keys its contract gives:
    =sns-roam-unknown-id=, =sns-roam-missing-file=,
    =sns-roam-malformed-note=, =sns-roam-unsupported-element= when org
    prints the element whose blank lines change as other text (the
    anchor when AFTER is non-nil, the element before the anchor when
    it is nil), and =sns-roam-diff-failure= after the save.

** Implementation

Three pure functions and a shell. =sns-roam--insert-beside= sets the
spacing over the full child list, as the warning on
=sns-roam--map-children= asks. =sns-roam--check-reparse= compares the
planned body with what org reads back from its text.
=sns-roam--insert-into-section= computes the new section from the old
one. It rejects a non-paragraph, finds the unique anchor among the
body elements, places the paragraph and checks the result.
=sns-roam-insert-element= passes that calculation through
=sns-roam--update-section=.

#+begin_src emacs-lisp
(defun sns-roam--insert-beside (children anchor new-element after)
  "Return CHILDREN with NEW-ELEMENT next to ANCHOR, a member of CHILDREN.
AFTER non-nil places it after ANCHOR, nil before.  The child in
front of NEW-ELEMENT keeps its post-blank, raised to at least 1,
unless it is header furniture, which is left as it was.  NEW-ELEMENT
gets post-blank 1 when a child follows it, and otherwise the
post-blank ANCHOR had.  Every other child is returned as it was.
Pure."
  (let ((at-least-one (lambda (node)
                        (org-ml-set-property
                         :post-blank
                         (max 1 (org-ml-get-property :post-blank node))
                         node))))
    (cl-mapcan
     (lambda (child next)
       (cond
        ((and (eq child anchor) after)
         (list (funcall at-least-one child)
               (org-ml-set-property
                :post-blank
                (if next 1 (org-ml-get-property :post-blank anchor))
                new-element)))
        ((eq child anchor)
         (list (org-ml-set-property :post-blank 1 new-element) child))
        ((and (eq next anchor) (not after)
              (not (sns-roam--section-header-p child)))
         (list (funcall at-least-one child)))
        (t (list child))))
     children
     (append (cdr children) (list nil)))))

(defun sns-roam--body-signature (children)
  "Return the type and trimmed text of each body element in CHILDREN."
  (mapcar (lambda (element)
            (list (org-ml-get-type element)
                  (org-ml-to-trimmed-string element)))
          (seq-remove #'sns-roam--section-header-p children)))

(defun sns-roam--check-reparse (section)
  "Return SECTION if its printed text parses back to the same body.
Compares the body elements of SECTION with those org reads from
`org-ml-to-string' of SECTION, by type and trimmed text.  Raises
`sns-roam-reparse-mismatch' on a mismatch, such as two elements merged
by too few blank lines; the write boundary adds the :file.  Pure."
  (let ((planned  (sns-roam--body-signature (org-ml-get-children section)))
        (reparsed (sns-roam--body-signature
                   (sns-roam--parse-body-elements (org-ml-to-string section)))))
    (unless (equal planned reparsed)
      (sns-roam--signal-reparse-mismatch planned reparsed))
    section))

(defun sns-roam--insert-into-section (section pred new-element after)
  "Return SECTION with paragraph NEW-ELEMENT beside the body element matching PRED.
PRED sees only body elements, never the property drawer or `#+'
keywords, and must match exactly one.  AFTER non-nil places
NEW-ELEMENT after the match, nil before.  Raises an `sns-roam:' error
when NEW-ELEMENT is not a paragraph, when PRED matches zero or many
elements, or when the result would not read back as planned.  Pure."
  (unless (org-ml-is-type 'paragraph new-element)
    (sns-roam--signal-unsupported-element (org-ml-get-type new-element)
                                          'sns-roam-insert-element))
  (let ((matches (seq-filter
                  (lambda (child)
                    (and (not (sns-roam--section-header-p child))
                         (funcall pred child)))
                  (org-ml-get-children section))))
    (unless (= 1 (length matches))
      (sns-roam--signal-match-count (length matches) 'sns-roam-insert-element))
    (sns-roam--check-reparse
     (sns-roam--map-children
      (lambda (children)
        (sns-roam--insert-beside children (car matches) new-element after))
      section))))

(defun sns-roam-insert-element (id pred new-element &optional after)
  "Insert paragraph NEW-ELEMENT beside the body element of node ID matching PRED.
PRED is a unary predicate on an org-ml node and sees only body
elements, never the property drawer or `#+' keywords.  NEW-ELEMENT
is a paragraph built with `org-ml-build-paragraph'.  AFTER non-nil
inserts after the match, nil before it.  No blank-line gap shrinks,
and every other element keeps its text.  Errors loudly, leaving the
file unchanged, when NEW-ELEMENT is not a paragraph, PRED matches
zero or many elements, the result would not read back as planned,
or ID is unknown.  Composes through `sns-roam--update-section'.
Returns (:id :file)."
  (sns-roam--update-section
   'sns-roam-insert-element id
   (lambda (section)
     (sns-roam--insert-into-section section pred new-element after))))
#+end_src

** Discipline notes

- *Unique-handle, loud failure.* Every error but
  =sns-roam-diff-failure= is raised inside the transform, before
  =sns-roam--update-section= changes the buffer, so nothing is saved.
  =sns-roam-diff-failure= comes after the save.
- *Additive.* No existing element changes text. Only the
  =:post-blank= of the element in front of the new paragraph can
  change, and only from 0 to 1.
- *Paragraphs only.* History lines are paragraphs, and a list beside
  a list would merge.
- *Body only.* Content under a headline is out of reach.

* Read: where a history line goes in a reference note

Find the paragraph a new dated history line goes beside, so Claude
can pass it to =insert-element= without choosing the place itself.
Claude never reads the note's file to choose the place, and never
rewrites the body with =set-body= to add a line.

The supported layout is the owner's reference note: paragraphs only,
no headings, tables or lists, with any undated paragraphs first and
the history last, one paragraph per line, newest first, each starting
=YYYY-MM-DD:=. The call checks only that layout, not the labels the
roam-distill skill uses for the undated paragraphs ("Current state:",
"Open:", "Related claims:"). A note with no dated paragraph is
accepted, and its anchor is the last paragraph, with =:after t=.

** Contract

- *Input*:
  - =ID= (string): the roam node UUID.
  - =DATE= (string): the event's date as =YYYY-MM-DD=.
- *Output*: plist =(:id ID :file FILE :anchor TEXT :after BOOL)=.
  - TEXT is the trimmed text of the first history line dated on or
    before DATE, with =:after= nil: the new line goes before it.
  - With no such line, TEXT is the last paragraph's and =:after= is
    =t=: the new line goes at the end.
- *Side effect*: none on disk. The note is parsed from the buffer
  =find-file-noselect= returns, as =sns-roam-body-elements= reads it,
  headings included. A note the owner has narrowed is read in full.
- *Errors*: =sns-roam-unknown-id= and =sns-roam-missing-file= for ID.
  The others carry =:id= and =:file=:
  - =sns-roam-bad-date= with =:date= when DATE is not =YYYY-MM-DD=.
  - =sns-roam-unsupported-element= with =:type= and
    =:operation sns-roam-history-anchor= when the note has a heading,
    with its =:title=, or a body element that is not a paragraph.
  - =sns-roam-history-layout= with =:reason no-paragraphs= when the
    body is empty, =not-one-run= when the dated lines are not one run
    at the end of the body, and =not-newest-first= with the two
    =:dates= out of order.
  - =sns-roam-match-count= with =:count=, =:operation= and =:anchor=
    when TEXT appears in two paragraphs.

** Implementation

=sns-roam--history-anchor-in= is the calculation: it takes the parsed
note's top-level children and the date, and returns the anchor or
raises. =sns-roam-history-anchor= reads the buffer and passes the
children in.

#+begin_src emacs-lisp
(defconst sns-roam--history-date-regexp
  "\\`\\([0-9]\\{4\\}-[0-9]\\{2\\}-[0-9]\\{2\\}\\):"
  "Match the date that opens a history line, such as \"2026-11-09:\".")

(defun sns-roam--history-line-date (text)
  "Return the YYYY-MM-DD date that opens TEXT, or nil if TEXT is undated."
  (when (string-match sns-roam--history-date-regexp text)
    (match-string 1 text)))

(defun sns-roam--history-body (top-level-children)
  "Return the body paragraphs of a note whose parsed children are TOP-LEVEL-CHILDREN.
Raises an `sns-roam:' error on a heading anywhere in the note, on a
body element that is not a paragraph, or on an empty body.  Pure."
  (let ((headline (seq-find (lambda (child) (org-ml-is-type 'headline child))
                            top-level-children)))
    (when headline
      (sns-roam--signal-unsupported-element
       'headline 'sns-roam-history-anchor
       (org-ml-get-property :raw-value headline))))
  ;; With no headline, the top level is the one section, or nothing in
  ;; an empty file.
  (let ((body (seq-remove #'sns-roam--section-header-p
                          (seq-mapcat #'org-ml-get-children top-level-children))))
    (unless body
      (sns-roam--signal-history-layout 'no-paragraphs))
    (dolist (element body)
      (unless (org-ml-is-type 'paragraph element)
        (sns-roam--signal-unsupported-element (org-ml-get-type element)
                                              'sns-roam-history-anchor)))
    body))

(defun sns-roam--check-history-run (dates)
  "Raise an `sns-roam:' error unless DATES end in one run of dates, newest first.
DATES holds each body paragraph's opening date, or nil for an
undated paragraph, in buffer order.  Pure."
  (let ((run (seq-drop-while #'null dates)))
    (when (memq nil run)
      (sns-roam--signal-history-layout 'not-one-run))
    (cl-mapc (lambda (newer older)
               (when (string< newer older)
                 (sns-roam--signal-history-layout 'not-newest-first
                                                  (list newer older))))
             run (cdr run))))

(defun sns-roam--history-anchor-in (top-level-children date)
  "Return (:anchor TEXT :after BOOL) for a line dated DATE in a parsed note.
TOP-LEVEL-CHILDREN are the children of the note's parsed org-data.
TEXT is the trimmed text of the first history line dated on or
before DATE, with :after nil; with no such line, TEXT is the last
paragraph's and :after is t.  Raises an `sns-roam:' error for a DATE
that is not YYYY-MM-DD, for a note outside the reference layout (see
`sns-roam--history-body' and `sns-roam--check-history-run'), or when
TEXT is the text of two paragraphs.  Pure."
  (unless (string-match-p "\\`[0-9]\\{4\\}-[0-9]\\{2\\}-[0-9]\\{2\\}\\'" date)
    (sns-roam--signal-bad-date date))
  (let* ((texts (mapcar #'org-ml-to-trimmed-string
                        (sns-roam--history-body top-level-children)))
         (dates (mapcar #'sns-roam--history-line-date texts))
         (_ (sns-roam--check-history-run dates))
         (position (seq-position dates date
                                 (lambda (line-date new-date)
                                   (and line-date
                                        (not (string< new-date line-date))))))
         (anchor (if position (nth position texts) (car (last texts)))))
    (let ((count (seq-count (lambda (text) (string= text anchor)) texts)))
      (when (> count 1)
        (sns-roam--signal-match-count count 'sns-roam-history-anchor anchor)))
    (list :anchor anchor :after (null position))))

(defun sns-roam-history-anchor (id date)
  "Return where a history line dated DATE goes in reference note ID.

Returns:
  (:id ID :file FILE :anchor TEXT :after BOOL)

TEXT is the trimmed text of the first history line dated on or
before DATE, with :after nil, so the new line goes before it.  With
no such line, TEXT is the last paragraph's and :after is t.  Pass
TEXT and :after to `sns-roam-insert-element' with a predicate that
compares `org-ml-to-trimmed-string' to TEXT.  The note is parsed
from the buffer `find-file-noselect' returns, headings included.
Writes nothing.  Errors loudly on an unknown ID, a DATE that is not
YYYY-MM-DD, and a note outside the reference layout."
  (let ((file (sns-roam--node-file-or-error id)))
    (with-current-buffer (find-file-noselect file)
      (append (list :id id :file file)
              (sns-roam--call-with-context
               (list :id id :file file)
               (lambda ()
                 ;; Choose from all of the history, even when the
                 ;; owner has narrowed the note.
                 (sns-roam--history-anchor-in
                  (org-ml-get-children (save-restriction
                                         (widen)
                                         (org-ml-parse-this-buffer)))
                  date)))))))
#+end_src

** Discipline notes

- *Read-only.* The call decides the place and writes nothing. The
  skill shows the change and calls =insert-element= only after the
  owner confirms.
- *One layout, loud refusal.* A note in any other layout is an
  error, never a guess at where its history is.
- *An equal date goes first.* A new line dated the same day as an
  existing one goes above it, so the newest news reads first.

* Mutate: set a section-level keyword

Set or replace a =#+KEY: value= keyword in the file's first section.
=#+title:= is the usual use, and the primitive works for any keyword
that holds one value.

** Contract

- *Input*:
  - =ID= (string): the roam node UUID.
  - =KEY= (string): the keyword name, *uppercase, without the leading*
    =#+= or the trailing colon, so =TITLE=, not =#+title:=. Org's
    parser stores keyword keys in upper case, and the call follows it.
  - =VALUE= (string): the new value.
- *Output*: =(:id :file :diff)=.
- *Side effect*: saves the file.
- *Errors*: those of the write boundary, =sns-roam--update-section=.
- *Discipline*:
  - If the keyword is present, the call replaces its value.
  - If it is absent, the call adds a new keyword as the section's last
    child, after any body elements before the first heading.
  - Idempotent: setting the same KEY and VALUE again leaves the file
    as it was, apart from edits the owner had not saved in the buffer,
    which the save writes.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--upsert-keyword (section key value)
  "Return SECTION with KEY's keyword set to VALUE.
Replaces existing keyword in place; appends if absent."
  (let* ((children (org-ml-get-children section))
         (found    nil)
         (updated  (mapcar
                    (lambda (c)
                      (if (and (org-ml-is-type 'keyword c)
                               (string= (org-ml-get-property :key c) key))
                          (progn
                            (setq found t)
                            (org-ml-set-property :value value c))
                        c))
                    children)))
    (org-ml-set-children
     (if found
         updated
       (append updated (list (org-ml-build-keyword key value))))
     section)))

(defun sns-roam-set-keyword (id key value)
  "Set #+KEY: VALUE in the top-level section of roam node ID.

KEY is the bare uppercase keyword name (e.g. \"TITLE\"); VALUE
is a string. Returns (:id :file :diff), as
`sns-roam--update-section' does.  Errors loudly on unknown ID
or missing top-level section."
  (sns-roam--update-section
   'sns-roam-set-keyword id
   (lambda (section)
     (sns-roam--upsert-keyword section key value))))

* Mutate: rename a node's file on disk

Rename the =.org= file of a roam node, keep its timestamp prefix, and
point any buffer visiting the file at the new path. The roam database
picks up the new path on the next sync.

** Contract

- *Input*:
  - =ID= (string): the roam UUID.
  - =NEW-SLUG= (string): the new body of the file name, between the
    timestamp prefix and the =.org= extension. Snake case is expected.
    The call does not clean it, which is the caller's job.
- *Output*: the new absolute file path.
- *Side effects*:
  - The file is renamed on disk.
  - Any buffer visiting the old path visits the new one, through
    =set-visited-file-name=.
- *Errors*:
  - =sns-roam-unknown-id= and =sns-roam-missing-file= for ID.
  - =sns-roam-malformed-note= with =:missing roam-filename=, =:id=,
    =:file= and =:name= when the file name lacks the
    =NNNNNNNNNNNNNN-= prefix.
  - =sns-roam-file-exists= with =:id= and =:path= when a file has the
    new name, the note's own file included.
- *Discipline*:
  - Keeps the timestamp prefix verbatim. A file name without one is
    an error, never a guess.
  - Never overwrites a file.
  - Does *not* update =#+title:= or any property: it renames the file
    only. =sns-roam-rename= changes both.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--split-roam-filename (path)
  "Return (PREFIX . SLUG) from a roam filename PATH.
PREFIX is the 14-digit timestamp + dash; SLUG is the body
between dash and =.org=. Errors if PATH doesn't match the
expected shape."
  (let ((name (file-name-nondirectory path)))
    (unless (string-match "^\\([0-9]\\{14\\}-\\)\\(.+\\)\\.org$" name)
      (sns-roam--signal-malformed-note 'roam-filename nil path nil name))
    (cons (match-string 1 name) (match-string 2 name))))

(defun sns-roam-rename-file (id new-slug)
  "Rename roam node ID's file to use NEW-SLUG, preserving the timestamp prefix.

Returns the new absolute path. Errors if ID is unknown, the
filename doesn't match the expected =TIMESTAMP-SLUG.org= shape,
or the destination already exists."
  (let* ((old-path (sns-roam--node-file-or-error id))
         (dir      (file-name-directory old-path))
         (parts    (sns-roam--call-with-context
                    (list :id id)
                    (lambda () (sns-roam--split-roam-filename old-path))))
         (prefix   (car parts))
         (new-name (concat prefix new-slug ".org"))
         (new-path (expand-file-name new-name dir)))
    (when (file-exists-p new-path)
      (sns-roam--signal-file-exists id new-path))
    (when (string= old-path new-path)
      (sns-roam--signal-file-exists id new-path new-slug))
    (let ((buf (find-buffer-visiting old-path)))
      (rename-file old-path new-path)
      (when buf
        (with-current-buffer buf
          (set-visited-file-name new-path nil t))))
    new-path))
#+end_src

* Mutate: rename a node (title + filename together)

Rewrite =#+title:= and rename the file's slug to match. The slug comes
from org-roam's own =org-roam-node-slug= for the node as the database
holds it after the title is saved. The database follows the new title
only when =org-roam-db-autosync-mode= is on; without it the slug comes
from the old title.

** Contract

- *Input*:
  - =ID= (string): the roam UUID.
  - =NEW-TITLE= (string): the new title.
- *Output*: plist =(:id ID :title NEW-TITLE :file NEW-PATH :diff DIFF)=,
  where DIFF is the =#+title:= change, labelled with the file's name
  before the rename.
- *Side effects*: the title is rewritten in the file, the file is
  renamed, and any visiting buffer follows it.
- *Errors*: those of =sns-roam-set-keyword=, then
  =sns-roam-unknown-id= when the node is gone after the title write,
  then those of =sns-roam-rename-file=. When the new file name exists,
  the new title stays written and =sns-roam-file-exists= is raised, so
  no diff is returned.
- *Discipline*: not transactional. The title is written first, then
  the file renamed. If the rename fails, the title is already
  rewritten, and the caller can retry the rename with another slug or
  rename by hand. The call never rolls the title back.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam-rename (id new-title)
  "Rewrite roam node ID's title to NEW-TITLE and rename its file to match.

Slug derivation uses `org-roam-node-slug' for parity with the
capture template. Returns a plist (:id :title :file :diff), where
:diff is the title change `sns-roam-set-keyword' made, labelled with
the file's name before the rename."
  (let* ((title-write (sns-roam-set-keyword id "TITLE" new-title))
         (node        (org-roam-node-from-id id))
         (_           (unless node
                        (sns-roam--signal-unknown-id id)))
         (slug        (org-roam-node-slug node))
         (new-path    (sns-roam-rename-file id slug)))
    (list :id id :title new-title :file new-path
          :diff (plist-get title-write :diff))))

* Mutate: create a new roam node

Create a fresh =.org= file in =org-roam-directory= with a
generated UUID, a timestamp-prefixed filename, and the standard
roam header, a =:PROPERTIES:= drawer and a =#+title:= keyword. The
new node is at once visible to =org-roam-node-list= and the rest of
the bridge primitives.

** Contract

- *Input*:
  - =TITLE= (string): the title people read.
  - =KIND= (string): "permanent", "literature", "fleeting" or any
    other string the caller treats as a kind. The call does not
    check it, and the caller uses a value it recognises.
  - =ELEMENTS= (list of org-ml AST nodes, optional): the body, as
    nodes =org-ml-build-*= produced, such as paragraphs, headlines or
    plain lists. Pass =nil= for an empty body. A caller with a string
    of org parses it with =org-ml-parse-this-buffer= first.
  - =ID= (string, optional): a UUID assigned in advance. Without it,
    =org-id-new= generates one. A caller that links new notes to each
    other passes IDs it minted beforehand.
  - =ALIASES= (list of strings, optional): written as =:ROAM_ALIASES:=
    in the property drawer when non-empty.
  - =CREATED-TIME= (Emacs internal time value, optional): when
    non-nil, used in place of =current-time= for both the =:CREATED:=
    property and the filename's 14-digit prefix. Both are formatted
    from the same time value, so they agree. Pass an internal time
    value, such as one from =current-time=, =encode-time= or
    =parse-iso8601-time-string=, never a formatted string. Callers
    that omit it get the current time.
  - =SLUG-SOURCE= (string, optional): slugified for the filename in
    place of TITLE. It keeps the file name plain when the title
    carries extra detail, such as an appended date.
- *Output*: plist =(:id ID :title TITLE :file PATH)=, with no =:diff=.
- *Side effects*:
  - The new file is written under =org-roam-directory= with
    =write-region= from a =with-temp-buffer=, so org-roam's autosync
    hook never sees it.
  - The new file is then indexed with =org-roam-db-update-file=, which
    records its node and its links in the database. Every edit
    primitive resolves an ID through the database, so a batch can
    edit, link and expand the new node straight away, with no
    =org-roam-db-sync= first. The links the body holds show as
    backlinks on their targets at once.
- *Errors*:
  - =sns-roam-file-exists= with =:id= and =:path= when the destination
    exists. The call raises before it writes or indexes anything, so
    the existing file and its rows stay as they were and no row
    names the new ID.
  - =sns-roam-id-conflict= with =:id=, =:registered= and =:path= when
    the database already holds ID for another file. The call raises
    before it writes anything. org-roam would only warn on the
    duplicate and keep resolving ID to the old file.
  - =sns-roam-index-failure= with =:id=, =:expected= and =:actual=
    when, after indexing, ID does not resolve to the new file.
- *Discipline*:
  - Never overwrites a file. A collision means a bug.
  - The slug comes from SLUG-SOURCE when given, else from TITLE,
    through =org-roam-node-slugify=, to match the capture template.
  - The timestamp prefix uses =current-time= by default. CREATED-TIME
    overrides both the prefix and the drawer property, so one date
    reaches both. With CREATED-TIME, the two timestamps are formatted
    from that one time value with =format-time-string=. Without it,
    each reads the clock separately, so the two can differ when the
    call crosses a second or a minute.
  - The =:CREATED:= property is written =[YYYY-MM-DD Day HH:MM]=, the
    capture template's =%U= form.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--org-timestamp-of (time)
  "Return TIME as an inactive Org timestamp string,
matching the capture template's =%U= output (e.g. \"[2026-05-31 Sun 09:14]\").
TIME is an emacs internal time value (as produced by
`current-time', `encode-time', `parse-iso8601-time-string', etc.)."
  (format-time-string "[%Y-%m-%d %a %H:%M]" time))

(defun sns-roam--filename-prefix-of (time)
  "Return TIME as a 14-digit YYYYMMDDhhmmss filename prefix.
TIME is an emacs internal time value."
  (format-time-string "%Y%m%d%H%M%S" time))

(defun sns-roam--build-header-properties (id created kind aliases)
  "Return the list of =node-property= elements for a roam header.
ALIASES is a list of strings; when non-empty an extra
=ROAM_ALIASES= property is appended."
  (let ((base (list (org-ml-build-node-property "ID" id)
                    (org-ml-build-node-property "CREATED" created)
                    (org-ml-build-node-property "KIND" kind))))
    (if aliases
        (append base
                (list (org-ml-build-node-property
                       "ROAM_ALIASES"
                       (mapconcat (lambda (a) (format "\"%s\"" a))
                                  aliases " "))))
      base)))

(defun sns-roam--registered-file (id)
  "Return the file the org-roam database holds for node ID, or nil.
Resolves through `org-roam-node-from-id', as the edit primitives do."
  (let ((node (org-roam-node-from-id id)))
    (when node
      (org-roam-node-file node))))

(defun sns-roam--separate-body-elements (elements)
  "Return ELEMENTS with a blank line after each one but the last.
`org-ml-build-paragraph' gives a paragraph a :post-blank of 0, so
built paragraphs written in a row share no blank line and org reads
them as one paragraph. An element that already asks for more blank
lines keeps them. The last element is left alone, so no blank line
appears before the first headline, as `sns-roam-set-body' writes it."
  (append (mapcar (lambda (element)
                    (org-ml-set-property
                     :post-blank
                     (max 1 (org-ml-get-property :post-blank element))
                     element))
                  (butlast elements))
          (last elements)))

(defun sns-roam-create-node (title kind &optional elements id aliases created-time slug-source)
  "Create a new roam node with TITLE and KIND, returning a plist.

Slugifies TITLE for the filename, writes the file under
`org-roam-directory' with the standard roam header (:ID,
:CREATED, :KIND, optional :ROAM_ALIASES:, #+title) followed by
ELEMENTS — a list of org-ml AST nodes forming the body. ID, if
nil, is freshly generated via `org-id-new'. ALIASES is an
optional list of strings; when non-empty written as
:ROAM_ALIASES: per org-roam convention. CREATED-TIME, if
non-nil, is an emacs internal time value used in place of
`current-time' for both the :CREATED: property and the
filename's 14-digit prefix; both outputs are formatted from the
same time value. SLUG-SOURCE, if non-nil, is slugified for the
filename in place of TITLE — use it to decouple the filename slug
from a title that carries extra detail (e.g. an appended date),
so the file stays cleanly named while the title remains human.
Indexes the new file in the org-roam database, so the edit
primitives can resolve the returned ID at once.
Returns (:id :title :file). Errors before writing anything if the
destination exists or the database holds ID for another file.
Errors after indexing if ID does not resolve to the new file."
  (let* ((id       (or id (org-id-new)))
         (slug     (org-roam-node-slugify (or slug-source title)))
         (prefix   (sns-roam--filename-prefix-of created-time))
         (filename (concat prefix "-" slug ".org"))
         (path     (expand-file-name filename org-roam-directory))
         (created  (sns-roam--org-timestamp-of created-time))
         (props    (sns-roam--build-header-properties id created kind aliases))
         (drawer   (apply #'org-ml-build-property-drawer props))
         (kw       (org-ml-build-keyword "title" title))
         ;; Split ELEMENTS into the leading paragraph-ish section
         ;; children (which co-exist with drawer + keyword in a single
         ;; section) and the trailing headlines (which sit as siblings).
         (split-pos (or (cl-position-if
                         (lambda (e) (eq (org-ml-get-type e) 'headline))
                         elements)
                        (length elements)))
         (section-children (sns-roam--separate-body-elements
                            (cl-subseq elements 0 split-pos)))
         (sibling-headlines (cl-subseq elements split-pos))
         (section  (apply #'org-ml-build-section
                          (append (list drawer kw) section-children)))
         (content  (mapconcat #'org-ml-to-string
                              (cons section sibling-headlines)
                              "")))
    (when (file-exists-p path)
      (sns-roam--signal-file-exists id path))
    ;; org-roam only warns when it indexes a node whose ID another
    ;; file already holds, and the ID keeps resolving to that file.
    ;; Refuse before writing, so a retried batch that reuses a
    ;; pre-minted ID cannot leave a second file claiming it.
    (let ((registered (sns-roam--registered-file id)))
      (when registered
        (sns-roam--signal-id-conflict id registered path)))
    (with-temp-buffer
      (insert content)
      (write-region (point-min) (point-max) path nil 'silent))
    ;; The edit primitives look IDs up in the database, so a node
    ;; that is only on disk is unknown to them until it is indexed.
    (org-roam-db-update-file path)
    ;; Indexing reports some failures only as warnings, so check that
    ;; the ID now resolves to the new file before reporting success.
    (let ((registered (sns-roam--registered-file id)))
      (unless (and registered (file-equal-p registered path))
        (sns-roam--signal-index-failure id path registered)))
    (list :id id :title title :file path)))
#+end_src

** Discipline notes

- *AST in, file out.* Org is chosen over plain text formats because
  the AST is what the code works on. Callers hand over nodes built
  with =org-ml-build-*=. The function builds the header AST itself and
  prints the union with =org-ml-to-string=. The body is never built
  from a string template. Callers with a string of org parse it with
  =org-ml-parse-this-buffer= and pass the parsed children.
- *Section and sibling headlines.* The =:PROPERTIES:= drawer and the
  =#+title:= keyword sit inside the file's leading =section= element.
  Body paragraphs and lists belong in that same section. Top-level
  headlines (=*=) are its siblings, not its children. The function
  sorts ELEMENTS into those two groups and assumes paragraphs come
  before the first headline. A paragraph a caller puts after a
  headline becomes a child of that headline, which is where org's
  structure puts it anyway.
- *KIND is a plain string.* No enum and no check. The taxonomy is the
  owner's, and a typo in the value should be visible in the file, not
  rejected by the API.

* Create: a dated meeting note

Create a fresh =fleeting= node for one occurrence of a recurring
meeting and open it for editing. Interactive: =M-x
sns-roam-meeting-note= prompts for the series name.

** Contract

- *Input*: =SERIES= (string), the stable series name, such as
  "alan-smithee-1-1", "pir-prep" or "incident-review". It is trimmed.
- *Output*: the =sns-roam-create-node= plist =(:id :title :file)=.
- *Side effects*: the new file is written through
  =sns-roam-create-node= and then visited.
- *Errors*: a =user-error=, not an =sns-roam-= kind, when the trimmed
  name is empty. Otherwise those of =sns-roam-create-node=.
- *Discipline*:
  - The title is SERIES with today's ISO date appended, so each
    occurrence is a distinct node in the node-find picker.

#+begin_src emacs-lisp
(defun sns-roam--meeting-title (series time)
  "Return the title for a meeting-note instance of SERIES at TIME.
Appends an ISO date so instances are distinguishable in the
node-find picker while sharing a series name. Pure."
  (format "%s %s" series (format-time-string "%Y-%m-%d" time)))

(defun sns-roam-meeting-note (series)
  "Create a dated note instance for a recurring meeting SERIES.

SERIES is the stable series name (e.g. \"alan-smithee-1-1\",
\"pir-prep\", \"incident-review\"). The new node's title is
SERIES with today's date appended (\"alan-smithee-1-1 2026-06-16\")
so each occurrence is a distinct, picker-distinguishable node;
the filename slug derives from the bare SERIES, so the file is
not double-dated (org already supplies the timestamp prefix).
KIND is \"fleeting\" — raw meeting capture, to be mined into
permanent notes later. Always creates a fresh instance — never
finds an existing node — so identical series names never
collide. Opens the new file for editing.

Returns the create plist (:id :title :file)."
  (interactive
   (list (read-string "Recurring meeting series (e.g. alan-smithee-1-1): ")))
  (let* ((trimmed (string-trim series)))
    (when (string-empty-p trimmed)
      (user-error "sns-roam-meeting-note: empty series name"))
    (let* ((now    (current-time))
           (title  (sns-roam--meeting-title trimmed now))
           (result (sns-roam-create-node title "fleeting" nil nil nil now trimmed)))
      (find-file (plist-get result :file))
      result)))
