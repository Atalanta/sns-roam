* Overview

Lisp-native bridge that lets Claude read (and eventually write) the
=org-roam= slipbox. The contract is plist-shaped s-expressions
between Emacs and Claude — no JSON, no XML.

Two-layer split:
- *Roam API* (=org-roam-node-list=, =org-roam-node-from-id=,
  =org-roam-backlinks-get=) for graph metadata and traversal.
- *org-ml* for body content / excerpts / structural edits (write
  side, later).

This file tangles to =lisp/sns-roam-api.el=, which is committed, and
is loaded with =(require 'sns-roam-api)=. From the repository root,
tangle with =mise run tangle=, or:

#+begin_src sh :tangle no
emacs --batch --load org --eval '(org-babel-tangle-file "src/roam-api.org")'
#+end_src

* Seed: find by metadata

The cheapest, highest-recall seed operation. Filter
=org-roam-node-list= by substring match against title, alias, or
tag. Returns a list of plists, one per matching node.

** Contract

- *Input*: a query string (case-insensitive substring).
- *Output*: list of plists =(:id :title :file :tags :aliases)=.
  Empty list on no match. Never =nil=-pollutes a field — missing
  tags / aliases come back as =nil=.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--node-to-plist (node)
  "Convert an `org-roam-node' NODE into a plist for Claude."
  (list :id       (org-roam-node-id node)
        :title    (org-roam-node-title node)
        :file     (org-roam-node-file node)
        :tags     (org-roam-node-tags node)
        :aliases  (org-roam-node-aliases node)))

(defun sns-roam-find-by-metadata (query)
  "Return roam nodes whose title, alias, or tag matches QUERY (substring, case-insensitive).

Each result is a plist of the shape
  (:id ID :title TITLE :file FILE :tags TAGS :aliases ALIASES).
QUERY is a string. Empty list on no match.

Deduped by :id — `org-roam-node-list' returns one entry per
(node, alias) pair, so a node with N aliases would otherwise
appear N+1 times."
  (let ((q (downcase query))
        (seen (make-hash-table :test 'equal))
        (results nil))
    (dolist (node (org-roam-node-list))
      (let* ((id      (org-roam-node-id node))
             (title   (or (org-roam-node-title node) ""))
             (aliases (org-roam-node-aliases node))
             (tags    (org-roam-node-tags node)))
        (when (and (not (gethash id seen))
                   (or (cl-search q (downcase title))
                       (cl-some (lambda (a) (cl-search q (downcase a))) aliases)
                       (cl-some (lambda (tg) (cl-search q (downcase tg))) tags)))
          (puthash id t seen)
          (push (sns-roam--node-to-plist node) results))))
    (nreverse results)))
#+end_src

** Discipline notes

- *Plist returns, always.* Per [[file:~/.claude/projects/-Users-stephen-nelsonsmith-Developer-aldi-compass/memory/roam_claude_design.md][roam-claude-design]]: no opaque
  =org-roam-node= structs leak across the API boundary. Claude
  reads plists, full stop.
- *Provenance baked in.* =:id= and =:file= ride along on every
  result so excerpts and citations are mechanical.
- *No truncation.* If the slipbox grows past the point where
  full-list scans hurt, we add an =:limit= keyword later — but
  silent caps are forbidden by the design discipline.

* Read: search note bodies

Substring search (case-insensitive) over the body text of every
=.org= file in =org-roam-directory=. Used as a seed step when
the query phrase isn't in any node's title, alias, or tag — per
the locked design's pipeline:

  1. Seed by metadata (=find-by-metadata=).
  2. *Seed by body* (this function).
  3. Expand into the graph (=expand=).
  4. Mine excerpts (=excerpt=, future).

Returned as a flat list of *hit* plists, one per match (a file
with three matches yields three results). Each hit carries:

- =:id= — the roam node UUID for the file (looked up via
  =org-id-get= at point 1).
- =:title=, =:file= — node identity from the roam DB.
- =:line= — 1-indexed line number.
- =:point= — buffer position of the match (suitable for
  =goto-char=).
- =:hit-text= — the whole line containing the match, trimmed.

The property drawer at the top of each file (=:ID:= UUID and
friends) is skipped so a search for a UUID-looking string
doesn't return every node. We do this by skipping until past
=#+title:=.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--skip-header ()
  "Move point past the file's =:PROPERTIES:= drawer and =#+title:= line.
Stays at point 1 if no header found. Cheap heuristic: search
forward for =#+title:=, move to the line after; otherwise leave
point at the start of buffer."
  (goto-char (point-min))
  (when (re-search-forward "^#\\+title:.*\n" nil t)
    (goto-char (match-end 0))))

(defun sns-roam--search-file (file query)
  "Return a list of hit plists for QUERY in FILE.
Empty list if no hits or file isn't a roam node."
  (let ((re (regexp-quote query))
        (case-fold-search t)
        (hits nil))
    (with-temp-buffer
      (insert-file-contents file)
      (let ((id (org-with-point-at 1 (org-id-get))))
        (when id
          (let* ((node (org-roam-node-from-id id))
                 (title (when node (org-roam-node-title node))))
            (sns-roam--skip-header)
            (while (re-search-forward re nil t)
              (let* ((point (match-beginning 0))
                     (line  (line-number-at-pos point))
                     (line-text
                      (string-trim
                       (buffer-substring-no-properties
                        (line-beginning-position)
                        (line-end-position)))))
                (push (list :id id
                            :title title
                            :file file
                            :line line
                            :point point
                            :hit-text line-text)
                      hits)))))))
    (nreverse hits)))

(defun sns-roam-body-search (query)
  "Return all body-text matches for QUERY across the roam slipbox.

Each result is a plist of the shape
  (:id ID :title TITLE :file FILE :line LINE :point POINT :hit-text TEXT).

Substring match, case-insensitive. The =:PROPERTIES:= drawer
and =#+title:= line are skipped so UUID/keyword noise doesn't
match. Files without an =:ID:= property drawer (i.e. not a roam
node) are skipped silently. Empty list on no match."
  (let ((files (directory-files-recursively
                org-roam-directory "\\.org\\'")))
    (cl-mapcan (lambda (f) (sns-roam--search-file f query)) files)))
#+end_src

* Read: expand a node (one-hop subgraph)

Given a roam node ID, return the set of nodes reachable in one
hop — both incoming (=backlinks=) and outgoing (=forward
links=). Returned as a subgraph plist =(:nodes (...) :edges
(...))=, never flattened, per the locked design.

- =:nodes= — the unique set of source/target nodes deduped by
  =:id=, each in the standard plist shape.
- =:edges= — the relationships, one plist per link. Carries
  =:source-id=, =:target-id=, =:direction= (=:forward= or
  =:backward=), =:point= (provenance), and =:context= (the
  outline path or surrounding text excerpt).

Backlinks come from =org-roam-backlinks-get= (roam already
indexes them). Forward links are walked with =org-ml= over the
file's AST — roam doesn't index forward links, and per the
design we use AST walking rather than text grep. Only =id:=
links count as edges; fuzzy =[[X]]= autovivification
placeholders are unresolved and don't (yet) participate in the
graph.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--backlink-edges (target-node)
  "Return a list of backlink edge plists pointing at TARGET-NODE."
  (mapcar
   (lambda (bl)
     (let ((source (org-roam-backlink-source-node bl)))
       (list :source-id  (org-roam-node-id source)
             :target-id  (org-roam-node-id target-node)
             :direction  :backward
             :point      (org-roam-backlink-point bl)
             :context    (plist-get (org-roam-backlink-properties bl)
                                    :outline))))
   (org-roam-backlinks-get target-node)))

(defun sns-roam--forward-link-edges (source-node)
  "Return a list of forward-link edge plists from SOURCE-NODE.
Only =id:= links count; fuzzy and external links are skipped."
  (let* ((file   (org-roam-node-file source-node))
         (parsed (with-temp-buffer
                   (insert-file-contents file)
                   (org-mode)
                   (org-ml-parse-this-buffer)))
         (links  (org-ml-match '(:any * link) parsed)))
    (cl-loop for link in links
             when (string= (org-ml-get-property :type link) "id")
             collect
             (let* ((target-id (org-ml-get-property :path link))
                    (children (org-ml-get-children link))
                    (text-raw (and (stringp (car-safe children))
                                   (car children)))
                    (text (and text-raw (substring-no-properties text-raw))))
               (list :source-id  (org-roam-node-id source-node)
                     :target-id  target-id
                     :direction  :forward
                     :point      (org-ml-get-property :begin link)
                     :context    text)))))

(defun sns-roam-expand (id)
  "Return the one-hop subgraph around roam node ID.

Result shape:
  (:nodes (PLIST ...)
   :edges (PLIST ...))

=:nodes= contains every source/target node touched by an edge,
deduped by =:id=, plus the centre node itself. =:edges= contains
all backlinks (=:direction :backward=) and forward links
(=:direction :forward=) as edge plists.

Loud failure if ID has no roam node."
  (let* ((centre (org-roam-node-from-id id))
         (_ (unless centre (error "sns-roam: no roam node with id %S" id)))
         (back-edges (sns-roam--backlink-edges centre))
         (fwd-edges  (sns-roam--forward-link-edges centre))
         (all-edges  (append back-edges fwd-edges))
         (other-ids  (delete-dups
                      (append (mapcar (lambda (e) (plist-get e :source-id)) back-edges)
                              (mapcar (lambda (e) (plist-get e :target-id)) fwd-edges))))
         (other-nodes (mapcar
                       (lambda (oid)
                         (let ((n (org-roam-node-from-id oid)))
                           (if n
                               (sns-roam--node-to-plist n)
                             ;; unresolved id — surface a stub
                             (list :id oid :title nil :file nil
                                   :tags nil :aliases nil))))
                       other-ids))
         (centre-plist (sns-roam--node-to-plist centre)))
    (list :nodes (cons centre-plist other-nodes)
          :edges all-edges)))
#+end_src

* Read: excerpt the element enclosing a point

Given a roam node ID and a buffer =POINT= inside its file, return
the smallest "excerpt container" element enclosing that point —
plus the headline ancestry leading to it. Used as the final mining
step in the locked design's read pipeline:

  1. Seed by metadata (=find-by-metadata=).
  2. Seed by body (=body-search=) — yields hit plists with =:point=.
  3. Expand into the graph (=expand=).
  4. *Mine excerpts* (this function) — turn a =:point= into the
     surrounding paragraph plus its outline path.
  5. Synthesise (Claude's job).

Pure transformation on the AST. No mutation, no buffer state.

** Contract

- *Input*:
  - =ID= (string) — roam node UUID. Loud failure if unknown.
  - =POINT= (integer) — buffer position inside the node's file.
- *Output*: plist
  =(:id :file :point :text :container-type :outline)=.
  - =:text= — the serialised excerpt container (a paragraph,
    item, quote-block, or verse-block).
  - =:container-type= — the symbol naming the container's element
    type. Lets a caller filter (e.g. mining quotes only).
  - =:outline= — list of headline plists, root-to-leaf ancestry,
    each =(:level :raw-value :tags :todo-keyword)=. Empty list
    when POINT is in the leading section before any headline.
- *Discipline*: loud failure if POINT has no enclosing excerpt
  container — that means POINT landed in a headline title line,
  a property-drawer, or somewhere structurally weird, which is a
  bug in whatever produced the POINT.

** Implementation

The walk: pre-order traversal of the AST collecting every element
whose =[:begin, :end)= window contains POINT. The result is the
ancestry chain root-to-leaf — order is implicit in the recursion.
Two pluckings derive =:outline= and the container from that chain.

The excerpt-container set excludes =plain-list=: a list's =item=
children are the better mining unit. A POINT in a list bullet
gets the bullet text, not the entire list.

#+begin_src emacs-lisp
(defconst sns-roam--excerpt-container-types
  '(paragraph item quote-block verse-block)
  "Element types that count as excerpt containers for mining.
Walks descend past =plain-list= to its =item= children — the item
is the better excerpt unit than the whole list.")

(defun sns-roam--element-contains-point-p (element point)
  "Return non-nil if POINT lies within ELEMENT's [:begin, :end) window."
  (let ((b (org-ml-get-property :begin element))
        (e (org-ml-get-property :end element)))
    (and b e (<= b point) (< point e))))

(defun sns-roam--ancestry-at-point (root point)
  "Return the ancestry chain of elements containing POINT under ROOT.
Result is root-to-leaf, including ROOT when it contains POINT.
Each element appears once. Pure: no buffer state, no mutation."
  (when (sns-roam--element-contains-point-p root point)
    (cons root
          (cl-loop for child in (org-ml-get-children root)
                   for sub = (and (listp child)
                                  (sns-roam--ancestry-at-point child point))
                   when sub return sub))))

(defun sns-roam--headline-to-plist (h)
  "Convert headline AST node H into a plist for Claude."
  (list :level         (org-ml-get-property :level h)
        :raw-value     (org-ml-get-property :raw-value h)
        :tags          (org-ml-get-property :tags h)
        :todo-keyword  (org-ml-get-property :todo-keyword h)))

(defun sns-roam-excerpt (id point)
  "Return the excerpt container enclosing POINT in roam node ID's file.

Result shape:
  (:id ID
   :file FILE
   :point POINT
   :text TEXT
   :container-type SYMBOL
   :outline (HEADLINE-PLIST ...))

Loud failure if ID is unknown or POINT has no enclosing excerpt
container (=paragraph= / =item= / =quote-block= / =verse-block=).
The latter usually means POINT landed in a headline title line or
a property drawer — fix the upstream caller."
  (let* ((file    (sns-roam--node-file-or-error id))
         (root    (with-temp-buffer
                    (insert-file-contents file)
                    (org-mode)
                    (org-ml-parse-this-buffer)))
         (chain   (sns-roam--ancestry-at-point root point))
         (outline (cl-loop for el in chain
                           when (org-ml-is-type 'headline el)
                           collect (sns-roam--headline-to-plist el)))
         (container
          (cl-loop for el in (reverse chain)
                   when (memq (org-ml-get-type el)
                              sns-roam--excerpt-container-types)
                   return el)))
    (unless container
      (error "sns-roam: point %d in %s has no enclosing excerpt container"
             point file))
    (list :id              id
          :file            file
          :point           point
          :text            (string-trim (org-ml-to-string container))
          :container-type  (org-ml-get-type container)
          :outline         outline)))
#+end_src

** Discipline notes

- *One walk, two pluckings.* =sns-roam--ancestry-at-point= produces
  the full root-to-leaf chain; =:outline= and the container are
  filters over that single result. Resist the temptation to write
  separate "find headlines" and "find paragraph" walkers — they'd
  duplicate the recursion and drift apart over time.
- *Loud failure when POINT has no container.* A property drawer or
  a headline title line is a sign that the upstream =:point= was
  built wrong (e.g. body-search hit something it shouldn't have).
  Surfacing the bug is more valuable than returning =nil=.
- *=plain-list= deliberately excluded from containers.* A user
  searching for text inside a bullet wants the bullet, not the
  whole list. Items nest cleanly; lists don't.
- *Predicate as data.* =sns-roam--excerpt-container-types= is a
  defconst, not buried in an =or= chain. Easy to extend (add
  =example-block= for code excerpts later) without touching the
  walk.

* Mutate: set a file-level property

Set or update a single property in the top-level =:PROPERTIES:=
drawer of a roam node's file. Used for retrofitting metadata
(=:KIND:=, =:CREATED:=, etc.) onto existing notes, and as the
foundation for any future =roam-distill= writes that touch
file-level metadata.

** Contract

- *Input*:
  - =ID= (string) — the roam node UUID. Located via
    =org-roam-node-from-id=. *Loud failure* if no such node exists.
  - =KEY= (string) — property name, without colons (e.g. =KIND=,
    not =:KIND:=).
  - =VALUE= (string) — property value.
- *Output*: =t= on success. Errors loudly otherwise.
- *Side effect*: rewrites the file on disk. The mutation is
  idempotent — calling twice with the same value is a no-op
  (writes the same bytes).
- *Discipline*: one node, one property, one call. No batching,
  no fuzzy match. Caller resolves the ID first.

** Implementation

Uses =org-ml= to parse the file's first =section=, find or build
its =property-drawer=, set the requested =node-property=, and
write back. Never =Edit='s the file as text.

#+begin_src emacs-lisp
(require 'org-ml)

(defun sns-roam--node-file-or-error (id)
  "Return the file path for roam node ID, or signal an error.
Loud failure on unknown ID — never returns nil."
  (let ((node (org-roam-node-from-id id)))
    (unless node
      (error "sns-roam: no roam node with id %S" id))
    (org-roam-node-file node)))

(defun sns-roam--upsert-node-property (drawer key value)
  "Return DRAWER with KEY set to VALUE.
If KEY already present, replace its value; otherwise append a new
node-property as the drawer's last child. Pure — does not mutate."
  (let* ((children (org-ml-get-children drawer))
         (found    nil)
         (updated  (mapcar
                    (lambda (np)
                      (if (and (org-ml-is-type 'node-property np)
                               (string= (org-ml-get-property :key np) key))
                          (progn
                            (setq found t)
                            (org-ml-set-property :value value np))
                        np))
                    children)))
    (org-ml-set-children
     (if found
         updated
       (append updated (list (org-ml-build-node-property key value))))
     drawer)))

(defun sns-roam-set-property (id key value)
  "Set property KEY to VALUE in the top-level drawer of roam node ID.

ID is a roam UUID; KEY is the bare property name (no colons);
VALUE is a string. Returns t on success. Errors if the node is
unknown, or if the file has no top-level section/drawer to
update (which would mean it isn't a well-formed roam file)."
  (let ((file (sns-roam--node-file-or-error id)))
    (with-current-buffer (find-file-noselect file)
      (let* ((tree     (org-ml-parse-this-buffer))
             (section  (car (org-ml-get-children tree))))
        (unless (and section (org-ml-is-type 'section section))
          (error "sns-roam: %s has no top-level section" file))
        (let* ((sec-children (org-ml-get-children section))
               (drawer       (cl-find-if
                              (lambda (c) (org-ml-is-type 'property-drawer c))
                              sec-children)))
          (unless drawer
            (error "sns-roam: %s has no top-level property-drawer" file))
          (let* ((new-drawer   (sns-roam--upsert-node-property drawer key value))
                 (new-section  (org-ml-set-children
                                (mapcar (lambda (c)
                                          (if (eq c drawer) new-drawer c))
                                        sec-children)
                                section))
                 (new-tree     (org-ml-set-children
                                (cons new-section
                                      (cdr (org-ml-get-children tree)))
                                tree)))
            (erase-buffer)
            (insert (org-ml-to-string new-tree))
            (save-buffer)
            t))))))
#+end_src

** Discipline notes

- *Loud failure on unknown ID.* No silent skip, no auto-create.
  If the caller passes a UUID that doesn't resolve, that's a bug
  upstream and we want the stack trace.
- *No append-if-no-drawer.* If a roam file somehow lacks a
  property-drawer, we error rather than build one. Building one
  is a different operation (=sns-roam-init-properties= or similar)
  with different semantics; conflating them hides bugs.
- *Idempotent on re-application.* Setting =:KIND:= to =permanent=
  twice writes the same bytes both times. Useful for retrofit
  scripts that may re-run.
- *Single-property granularity.* Multi-property updates compose
  by repeated calls. Resist the urge to add a batched API until
  we have a real callsite that needs it.

* Mutate: replace the body of a node

Replace the paragraphs and other body elements that come before
the first heading with new content. Property drawers, standalone
=#+= keywords (=#+title:=, =#+filetags:=) and every existing
heading with its content stay as they are. Affiliated keywords
(=#+name:=, =#+caption:=) belong to the element below them and are
removed with it. To change a heading, edit it by hand.

Used for trimming / rewriting fleeting captures into atomic
permanent notes. The minimum viable body-write — surgical
paragraph edits are a later primitive.

** Contract

- *Input*:
  - =ID= (string) — the roam node UUID. Loud failure if unknown.
  - =NEW-BODY= (string) — the replacement body text. May be empty.
    Should *not* include the property drawer or =#+title:= line —
    those are preserved automatically. Trailing newline normalised
    (we ensure the file ends in exactly one =\n=).
- *Output*: =(:id :file)=.
- *Side effect*: rewrites the file on disk.
- *Discipline*: replaces the body elements before the first
  heading. There is no merge, no append. If you want to add to
  existing content there, read it first, concatenate, and call
  this with the result.

** Implementation

This is the first of the /composed/ write primitives. Rather than
poke the buffer imperatively, body mutations are expressed as a
*pure transform* over the note's =section= AST, handed to a single
shared write boundary. Three layers:

1. =sns-roam--map-children= — a pure =(section -> section)= that
   applies a function to the section's full child list. Operates on
   the list whole (filter to keep, append to add); never slices
   parsed nodes into sublists. No I/O.
2. =sns-roam--update-section= — the *one* effect boundary every body
   mutation flows through: read → parse → apply a pure section
   transform → reconcile the buffer via =org-ml-update-this-buffer=
   (Myers-diff, so overlays/cursor survive) → save.
3. =sns-roam-set-body= et al. — thin shells: a pure transform
   composed through the boundary.

=set-body= keeps its string interface (callers pass prose, not AST);
internally the prose is parsed to body elements and those *replace*
the existing body. Drawer and =#+title:= are never touched.

#+begin_src emacs-lisp
(defun sns-roam--section-header-p (element)
  "Non-nil if ELEMENT is roam header furniture (property-drawer or keyword)."
  (or (org-ml-is-type 'property-drawer element)
      (org-ml-is-type 'keyword element)))

(defun sns-roam--map-children (fn section)
  "Return SECTION with FN applied to its full child list.
FN takes the section's children (header furniture + body) and
returns a new child list. Pure: returns a new section, mutates
nothing.

IMPORTANT: operate on the child list as a whole — do NOT slice it
into header/body sublists and re-`append` them. Parsed nodes carry
buffer positions and :parent backrefs; reassembling sliced sublists
of parsed nodes corrupts those, and `org-ml-update-this-buffer`'s
reconciliation then fails with `number-or-marker-p`. Filtering the
list in place (e.g. `seq-filter`) is safe; slicing-and-rejoining is
not.

Body helpers are expressed in terms of this:
- append: `(append children NEW)` — header stays in front untouched.
- replace-body: `(append (seq-filter #'sns-roam--section-header-p
  children) NEW-BODY)` — keep header, drop old body, add new."
  (org-ml-map-children fn section))

(defun sns-roam--parse-body-elements (string)
  "Parse STRING of org prose into a list of body elements.
A bare string parses to a single headline-less section; we return
that section's children. Empty STRING yields nil."
  (if (string-empty-p string)
      nil
    (let* ((tree    (with-temp-buffer
                      (insert string)
                      (org-ml-parse-this-buffer)))
           (section (car (org-ml-get-children tree))))
      (if section (org-ml-get-children section) nil))))

(defun sns-roam--update-section (id section-fn)
  "Apply pure SECTION-FN (section -> section) to node ID and save.
The single write boundary for body mutations: parse → transform →
reconcile buffer (`org-ml-update-this-buffer`, minimal-diff) → save.
Loud failure on unknown ID or malformed file. Returns (:id :file)."
  (let ((file (sns-roam--node-file-or-error id)))
    (with-current-buffer (find-file-noselect file)
      (org-ml-update-this-buffer
       (lambda (data)
         (let* ((children (org-ml-get-children data))
                (section  (car children)))
           (unless (and section (org-ml-is-type 'section section))
             (error "sns-roam: %s has no top-level section" file))
           (org-ml-set-children
            (cons (funcall section-fn section) (cdr children))
            data))))
      (save-buffer)
      (list :id id :file file))))

(defun sns-roam-set-body (id new-body)
  "Replace the body of roam node ID with NEW-BODY.

The paragraphs and other body elements before the first heading
are replaced with NEW-BODY parsed as org prose. Property drawers,
standalone =#+= keywords (=#+title:=, =#+filetags:=) and every
existing heading with its content stay. Affiliated keywords
(=#+name:=, =#+caption:=) go with the element they precede.
NEW-BODY is a string; empty clears those body elements.
Returns (:id :file). Errors loudly on unknown ID or malformed file."
  (sns-roam--update-section
   id
   (lambda (section)
     (sns-roam--map-children
      (lambda (children)
        (append (seq-filter #'sns-roam--section-header-p children)
                (sns-roam--parse-body-elements new-body)))
      section))))
#+end_src

** Discipline notes

- *Pure transform, one effect boundary.* The body operation is a
  pure =(section -> section)=; the only I/O lives in
  =sns-roam--update-section=. Every future body primitive (append,
  promote, merge) composes the same way — the module composes
  transforms rather than accreting buffer-poking procedures.
- *Header preserved structurally, not by byte-position.* The
  transform =seq-filter='s header furniture and re-prepends the new
  body; no reliance on cursor positions or =delete-region=. It
  operates on the child list as a whole (never slicing parsed nodes
  into sublists — see the warning on =sns-roam--map-children=).
- *Empty body is valid.* =""= parses to nil → an empty body.
- *Return shape changed* from =t= to =(:id :file)= for provenance
  parity with the other mutators.

* Mutate: append a relationship link

Append a link from one note to another — the core Zettelkasten act
of connecting ideas as you spot the connection. The link is added
as a new body paragraph: a relationship sentence with an inline
=[[id:...]]= link, so the connection carries its reasoning (per the
claim-graph design — links are statements, not decoration).

One-directional: org-roam provides backlinks for free, so the
reverse direction is discoverable without a second physical link.

** Contract

- *Input*:
  - =FROM-ID= (string) — the note gaining the link. Loud failure if unknown.
  - =TO-ID= (string) — the link target. Loud failure if unknown.
  - =LABEL= (string) — the link's display text.
  - =BEFORE= (string) — prose before the link in the paragraph.
  - =AFTER= (string) — prose after the link (e.g. =". "=, trailing
    clause, or full stop). Lets the link sit anywhere in a sentence
    and keeps punctuation honest, rather than forcing the link to the
    end. Pass =""= for nothing after.
- *Output*: =(:from :to :file)=.
- *Side effect*: appends one paragraph to FROM-ID's body.
- *Discipline*: existing content is untouched (additive only). Both
  endpoints validated before any mutation. The primitive is *dumb* —
  it does not check whether the link already exists; that policy
  belongs to the orchestrating skill (=roam-distill=), keeping the
  primitive a single honest mutation.

** Implementation

A pure body transform (append one paragraph) composed through
=sns-roam--update-section=. No buffer-poking; the paragraph is built
as an AST node and appended to the body element list. =BEFORE= and
=AFTER= bracket the link so the caller controls phrasing and
punctuation; empty strings are dropped so no stray empty text nodes
appear.

#+begin_src emacs-lisp
(defun sns-roam-append-link (from-id to-id label before after)
  "Append a relationship paragraph to FROM-ID linking to TO-ID.
The paragraph reads BEFORE then an inline [[id:TO-ID][LABEL]] link
then AFTER, and becomes the last body element. Existing content is
untouched. One-directional; org-roam backlinks give the reverse.
The primitive does NOT dedupe — call it once per intended link.
Loud failure if FROM-ID or TO-ID is unknown. Returns (:from :to :file)."
  (sns-roam--node-file-or-error to-id)  ; validate target exists, loud
  (let* ((link  (org-ml-build-link (concat "id:" to-id) label))
         ;; Drop empty BEFORE/AFTER so no empty secondary-strings sneak in.
         (parts (seq-remove (lambda (x) (and (stringp x) (string-empty-p x)))
                            (list before link after)))
         (res (sns-roam--update-section
              from-id
              (lambda (section)
                (sns-roam--map-children
                 (lambda (children)
                   (append children
                           (list (apply #'org-ml-build-paragraph parts))))
                 section)))))
    (list :from from-id :to to-id :file (plist-get res :file))))
#+end_src

** Discipline notes

- *Additive, not surgical.* This appends; it never rewrites existing
  elements. Whole-element replacement is =sns-roam-replace-element=
  below; both compose through =sns-roam--update-section=.
- *One-directional by design.* Backlinks cover the reverse. A
  bidirectional variant (for symmetric relations like "contradicts")
  would be a separate, explicit primitive.

* Read: the body elements of a node

Return the body elements before a note's first heading, as parsed
org-ml nodes, so Claude can show the text an edit will replace. The
roam-distill transform flow calls this before =replace-element= or
=set-body=. Reading the file and splitting on blank lines guesses at
paragraph boundaries that org decides (issue #7).

** Contract

- *Input*: =ID= (string), the roam node UUID. Loud failure if
  unknown.
- *Output*: plist =(:id ID :file FILE :elements NODES)=.
  - =:elements=: the section's children with the header furniture
    (property drawer, =#+= keywords) removed, in buffer order. Nil
    when the note has no body before its first heading, or when the
    file opens straight onto a heading.
- *Side effect*: none on disk. The file is visited with
  =find-file-noselect=, as =sns-roam--update-section= visits it, so a
  buffer the owner has open is parsed with its unsaved edits, and the
  text returned is the text the following edit acts on. Nothing is
  saved and the buffer's modified flag is left as it was.

** Implementation

The read mirrors the write boundary: same ID resolution, same buffer,
same header predicate. It filters the child list whole, as the
warning on =sns-roam--map-children= asks.

#+begin_src emacs-lisp
(defun sns-roam-body-elements (id)
  "Return the body elements before the first heading of roam node ID.

Returns:
  (:id ID :file FILE :elements NODES)

NODES are the parsed org-ml children of the note's first section,
without the property drawer and `#+' keywords, in buffer order; nil
when there is no such body.  The note is parsed from the buffer
`find-file-noselect' returns, the one `sns-roam--update-section'
edits, so unsaved edits are included.  Writes nothing.  Errors
loudly on an unknown ID."
  (let ((file (sns-roam--node-file-or-error id)))
    (with-current-buffer (find-file-noselect file)
      (let ((first-child (car (org-ml-get-children
                               (org-ml-parse-this-buffer)))))
        (list :id       id
              :file     file
              :elements (when (org-ml-is-type 'section first-child)
                          (seq-remove #'sns-roam--section-header-p
                                      (org-ml-get-children first-child))))))))
#+end_src

** Discipline notes

- *Same buffer as the write.* Reading the file from disk would show
  the saved text while =update-section= edits the buffer, so the
  before text shown to the owner could differ from what the edit
  replaces.
- *Nodes, not strings.* The caller serialises with
  =org-ml-to-trimmed-string= where it shows them, and can build a
  =replace-element= predicate from the same nodes.

* Mutate: replace a body element

Surgically replace one body element — rewrite a claim's paragraph,
swap a stale sentence — without reproducing the rest of the body
(which whole-body =set-body= would force). The element to change is
identified by a predicate; exactly one must match, so an ambiguous
edit never silently hits the wrong place.

** Contract

- *Input*:
  - =ID= (string) — the roam node UUID. Loud failure if unknown.
  - =PRED= (function) — a unary predicate on an org-ml node. Must
    match *exactly one* body element; zero or many is a loud error.
  - =NEW-ELEMENT= (org-ml node) — the replacement, built via
    =org-ml-build-*=.
- *Output*: =(:id :file)=.
- *Side effect*: replaces the matched element in FROM's body.
- *Discipline*: unique-handle — never guesses among multiple matches.
  AST in, AST out; no string-munging. Replaces an element *whole*; it
  does not edit *within* an element (that is a deeper, separate need).

** Implementation

A pure transform — match by predicate, assert uniqueness, map the
match to NEW-ELEMENT — composed through =sns-roam--update-section=.
The predicate runs over the whole section but naturally targets body
elements (header furniture rarely matches a content predicate).

#+begin_src emacs-lisp
(defun sns-roam-replace-element (id pred new-element)
  "Replace the unique body element of node ID matching PRED with NEW-ELEMENT.
PRED is a unary predicate on an org-ml node; NEW-ELEMENT is a built
org-ml node. Asserts exactly one match — loud error on zero or many,
so an ambiguous edit never silently hits the wrong element. Composes
through `sns-roam--update-section'. Returns (:id :file)."
  (sns-roam--update-section
   id
   (lambda (section)
     (let ((matches (org-ml-match `((:pred ,pred)) section)))
       (unless (= 1 (length matches))
         (error "sns-roam: replace-element matched %d elements, need exactly 1"
                (length matches)))
       (org-ml-match-map `((:pred ,pred))
                         (lambda (_old) new-element)
                         section)))))
#+end_src

** Discipline notes

- *Unique-handle, loud failure.* Zero or many matches errors rather
  than guessing — the wrong-element edit does not exist as an outcome.
- *Whole-element only.* Replaces a matched element entirely. Editing
  inside an element (fix one word in a paragraph) is a deeper need not
  served here; build the new element and replace.
- *Composes upward.* Merge/split flows are =replace-element= +
  =append-link= + =create-node=, orchestrated by the skill.

* Mutate: insert a body element next to another

Add one element beside an existing body element, and leave every
other element as it was. A history line in a reference note is the
usual case. =set-body= would make Claude reproduce every paragraph
for a one-element change. On 2026-11-10 a rewrite of one paragraph
dropped a line (issues #8 and #10).

** Contract

- *Input*:
  - =ID= (string): the roam node UUID. Loud failure if unknown.
  - =PRED= (function): a unary predicate on an org-ml node. It sees
    only body elements, never the property drawer or =#+= keywords.
    It must match *exactly one*; zero or many is a loud error and the
    file is unchanged.
  - =NEW-ELEMENT= (org-ml node): the element to add, built via
    =org-ml-build-*=. Its =:post-blank= is set by the call.
  - =AFTER= (optional): non-nil inserts after the anchor; nil
    inserts before it.
- *Output*: =(:id :file)=.
- *Side effect*: adds NEW-ELEMENT to the body of ID's file.
- *Spacing*: one blank line separates the new element from its
  anchor, and at least one separates it from the body element on its
  other side, because org joins a paragraph to prose or a table that
  follows it with no blank line. The blank lines that followed the
  pair before the call still follow it, so extra spacing survives,
  and no blank line appears before a first headline that had none.

** Implementation

A pure transform composed through =sns-roam--update-section=. It
finds the anchor among the body children. It then maps over the full
child list, as the warning on =sns-roam--map-children= asks. Each
child is paired with the one after it. That lets the body element in
front of an inserted-before element gain a blank line. The anchor comes out
paired with the new element. Every other child keeps its text, and
only that one neighbour's =:post-blank= can change.

#+begin_src emacs-lisp
(defun sns-roam--insert-beside (children anchor new-element after)
  "Return CHILDREN with NEW-ELEMENT next to ANCHOR, a member of CHILDREN.
AFTER non-nil places it after ANCHOR, nil before.  The first of the
pair takes post-blank 1, and the second takes the post-blank ANCHOR
had, so the spacing after the pair is what followed ANCHOR before.
That second post-blank is at least 1 when a child follows.  The body
child in front of an inserted-before pair also gets at least 1.  Org
joins a paragraph to prose or a table with no blank line between.
Every other child is returned as it was.  Pure."
  (let ((anchor-blank (org-ml-get-property :post-blank anchor))
        (at-least-one (lambda (node)
                        (org-ml-set-property
                         :post-blank
                         (max 1 (org-ml-get-property :post-blank node))
                         node))))
    (cl-mapcan
     (lambda (child next)
       (cond
        ((and (eq child anchor) after)
         (let ((pair-end (org-ml-set-property :post-blank anchor-blank
                                              new-element)))
           (list (org-ml-set-property :post-blank 1 child)
                 (if next (funcall at-least-one pair-end) pair-end))))
        ((eq child anchor)
         (list (org-ml-set-property :post-blank 1 new-element) child))
        ((and (eq next anchor) (not after)
              (not (sns-roam--section-header-p child)))
         (list (funcall at-least-one child)))
        (t (list child))))
     children
     (append (cdr children) (list nil)))))

(defun sns-roam-insert-element (id pred new-element &optional after)
  "Insert NEW-ELEMENT beside the unique body element of node ID matching PRED.
PRED is a unary predicate on an org-ml node and sees only body
elements, never the property drawer or `#+' keywords.  NEW-ELEMENT
is a built org-ml node.  AFTER non-nil inserts after the match, nil
before it.  One blank line separates the two; the blank lines that
followed the match still follow the pair.  Every other element keeps
its text.  Errors loudly, leaving the file unchanged, when PRED
matches zero or many elements or ID is unknown.  Composes through
`sns-roam--update-section'.  Returns (:id :file)."
  (sns-roam--update-section
   id
   (lambda (section)
     (sns-roam--map-children
      (lambda (children)
        (let ((matches (seq-filter
                        (lambda (child)
                          (and (not (sns-roam--section-header-p child))
                               (funcall pred child)))
                        children)))
          (unless (= 1 (length matches))
            (error "sns-roam: insert-element matched %d elements, need exactly 1"
                   (length matches)))
          (sns-roam--insert-beside children (car matches) new-element after)))
      section))))
#+end_src

** Discipline notes

- *Unique-handle, loud failure.* The error is raised inside the
  transform, before =org-ml-update-this-buffer= changes the buffer,
  so nothing is saved.
- *Additive.* No existing element changes text; only the anchor's
  =:post-blank= changes when the new element goes after it.
- *Body only.* Content under a headline is out of reach (issue #2).

* Mutate: set a section-level keyword

Set or replace a =#+KEY: value= keyword in the file's first
section. =#+title:= is the canonical use, but the primitive is
generic — works for any single-valued section keyword.

** Contract

- *Input*:
  - =ID= (string) — the roam node UUID. Loud failure if unknown.
  - =KEY= (string) — keyword name, *uppercase, without leading*
    =#+= or trailing colon (so =TITLE=, not =#+title:=). Org's
    parser stores keyword keys uppercased; we follow that.
  - =VALUE= (string) — the new value.
- *Output*: =t= on success.
- *Side effect*: rewrites the file on disk.
- *Discipline*:
  - If the keyword is already present, replaces its value.
  - If absent, appends a new keyword as the section's last
    header element (after the property drawer and any existing
    keywords).
  - Idempotent: same KEY+VALUE twice writes the same bytes.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--upsert-keyword (section key value)
  "Return SECTION with KEY's keyword set to VALUE.
Replaces existing keyword in place; appends if absent."
  (let* ((children (org-ml-get-children section))
         (found    nil)
         (updated  (mapcar
                    (lambda (c)
                      (if (and (org-ml-is-type 'keyword c)
                               (string= (org-ml-get-property :key c) key))
                          (progn
                            (setq found t)
                            (org-ml-set-property :value value c))
                        c))
                    children)))
    (org-ml-set-children
     (if found
         updated
       (append updated (list (org-ml-build-keyword key value))))
     section)))

(defun sns-roam-set-keyword (id key value)
  "Set #+KEY: VALUE in the top-level section of roam node ID.

KEY is the bare uppercase keyword name (e.g. \"TITLE\"); VALUE
is a string. Returns t on success. Errors loudly on unknown ID
or missing top-level section."
  (let ((file (sns-roam--node-file-or-error id)))
    (with-current-buffer (find-file-noselect file)
      (let* ((tree    (org-ml-parse-this-buffer))
             (section (car (org-ml-get-children tree))))
        (unless (and section (org-ml-is-type 'section section))
          (error "sns-roam: %s has no top-level section" file))
        (let* ((new-section (sns-roam--upsert-keyword section key value))
               (new-tree    (org-ml-set-children
                             (cons new-section
                                   (cdr (org-ml-get-children tree)))
                             tree)))
          (erase-buffer)
          (insert (org-ml-to-string new-tree))
          (save-buffer)
          t)))))
#+end_src

* Mutate: rename a node's file on disk

Rename the =.org= file backing a roam node, preserving the
timestamp prefix and updating the visiting buffer (if any) so
nothing stales out. The roam DB picks up the new path on next
sync.

** Contract

- *Input*:
  - =ID= (string) — the roam UUID. Loud failure if unknown.
  - =NEW-SLUG= (string) — the new filename body (between
    timestamp prefix and =.org= extension). Snake_case
    expected; we don't sanitise — caller's responsibility.
- *Output*: the new absolute file path on success.
- *Side effect*:
  - File renamed on disk.
  - Any buffer visiting the old path is updated via
    =set-visited-file-name= so it now visits the new path.
- *Discipline*:
  - Preserves the existing timestamp prefix verbatim. If the
    filename doesn't have a recognisable =NNNNNNNNNNNNNN-= prefix,
    error loudly rather than guess.
  - Errors if the destination filename already exists.
  - Does *not* update =#+title:= or any properties — pure
    filename operation. Composite renames live in
    =sns-roam-rename=.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--split-roam-filename (path)
  "Return (PREFIX . SLUG) from a roam filename PATH.
PREFIX is the 14-digit timestamp + dash; SLUG is the body
between dash and =.org=. Errors if PATH doesn't match the
expected shape."
  (let ((name (file-name-nondirectory path)))
    (unless (string-match "^\\([0-9]\\{14\\}-\\)\\(.+\\)\\.org$" name)
      (error "sns-roam: %s does not match roam filename shape" name))
    (cons (match-string 1 name) (match-string 2 name))))

(defun sns-roam-rename-file (id new-slug)
  "Rename roam node ID's file to use NEW-SLUG, preserving the timestamp prefix.

Returns the new absolute path. Errors if ID is unknown, the
filename doesn't match the expected =TIMESTAMP-SLUG.org= shape,
or the destination already exists."
  (let* ((old-path (sns-roam--node-file-or-error id))
         (dir      (file-name-directory old-path))
         (parts    (sns-roam--split-roam-filename old-path))
         (prefix   (car parts))
         (new-name (concat prefix new-slug ".org"))
         (new-path (expand-file-name new-name dir)))
    (when (file-exists-p new-path)
      (error "sns-roam: refusing to overwrite existing file %s" new-path))
    (when (string= old-path new-path)
      (error "sns-roam: new slug %S produces the same filename" new-slug))
    (let ((buf (find-buffer-visiting old-path)))
      (rename-file old-path new-path)
      (when buf
        (with-current-buffer buf
          (set-visited-file-name new-path nil t))))
    new-path))
#+end_src

* Mutate: rename a node (title + filename together)

Composite operation: rewrite =#+title:= and rename the file's
slug to match. Slug derivation uses org-roam's own
=org-roam-node-slug= so the result is byte-identical to what a
fresh capture would have produced.

** Contract

- *Input*:
  - =ID= (string) — the roam UUID.
  - =NEW-TITLE= (string) — the new title.
- *Output*: plist =(:id ID :title NEW-TITLE :file NEW-PATH)=.
- *Side effects*: title rewritten in file; file renamed; any
  visiting buffer updated.
- *Discipline*: not transactional. Title write happens first,
  then file rename. If the rename fails (e.g. destination exists),
  the title is already rewritten — caller can retry the rename
  with a different slug or rename by hand. We accept this because
  the alternative (rollback the title write) doubles the failure
  surface for marginal benefit.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam-rename (id new-title)
  "Rewrite roam node ID's title to NEW-TITLE and rename its file to match.

Slug derivation uses `org-roam-node-slug' for parity with the
capture template. Returns a plist (:id :title :file)."
  (sns-roam-set-keyword id "TITLE" new-title)
  (let* ((node    (org-roam-node-from-id id))
         (_       (unless node
                    (error "sns-roam: node %S vanished after title rewrite" id)))
         (slug    (org-roam-node-slug node))
         (new-path (sns-roam-rename-file id slug)))
    (list :id id :title new-title :file new-path)))
#+end_src

* Mutate: create a new roam node

Create a fresh =.org= file in =org-roam-directory= with a
generated UUID, a timestamp-prefixed filename, and the standard
roam header (=:PROPERTIES:= drawer + =#+title:= keyword). The new
node is immediately visible to =org-roam-node-list= and the rest
of the bridge primitives.

** Contract

- *Input*:
  - =TITLE= (string) — human-readable title.
  - =KIND= (string) — one of "permanent" / "literature" /
    "fleeting", or any other string the caller treats as a kind.
    No validation — caller's responsibility to use a recognised
    value. (Validation belongs in a higher layer if at all.)
  - =ELEMENTS= (list of org-ml AST nodes, optional) — body
    content as pre-built AST. Each element is something
    =org-ml-build-*= produced (paragraph, headline, plain-list,
    etc.). Pass =nil= for an empty-body node. Callers building
    from a string of pre-formatted org should parse it via
    =org-ml-parse-this-buffer= first; see the importer for the
    canonical pattern.
  - =ID= (string, optional) — pre-assigned UUID. If absent, a
    fresh one is generated via =org-id-new=. The importer uses
    this to honour a slug→UUID map computed before any files
    exist; the capture-template case omits it.
  - =ALIASES= (list of strings, optional) — written as
    =:ROAM_ALIASES:= in the property drawer when non-empty.
  - =CREATED-TIME= (emacs internal time value, optional) — when
    non-nil, used in place of =current-time= for both the
    =:CREATED:= property and the filename's 14-digit prefix.
    The two outputs are formatted from the *same* time value, so
    they're guaranteed consistent. Pass an internal time value
    (e.g. from =current-time=, =encode-time=,
    =parse-iso8601-time-string=) — never a pre-formatted string.
    The importer threads a derived creation time here so imported
    notes preserve their authored timestamps; capture-template
    callers omit it and get =now=.
  - =SLUG-SOURCE= (string, optional): slugified for the filename in
    place of TITLE. Use it to decouple the filename slug from a
    title that carries extra detail (e.g. an appended date), so the
    file stays cleanly named while the title remains human.
- *Output*: plist =(:id ID :title TITLE :file PATH)=.
- *Side effects*:
  - New file written under =org-roam-directory= via
    =write-region= over a =with-temp-buffer=, so org-roam's
    autosync hook never sees it.
  - The new file is then indexed with =org-roam-db-update-file=,
    which records its node and its links in the database. Every
    edit primitive resolves an ID through the database, so a batch
    can edit, link and expand the new node straight away, with no
    =org-roam-db-sync= first (issue #6). The links the body holds
    show as backlinks on their targets at once.
  - When the destination already exists, the function errors
    before it writes or indexes anything, so the existing file and
    its rows stay as they were and no row names the new ID.
  - When the database already holds ID for another file, the
    function errors before it writes anything. org-roam would only
    warn on the duplicate and keep resolving ID to the old file.
  - After indexing, the function errors unless ID resolves to the
    new file, naming the ID and both paths.
- *Discipline*:
  - Errors loudly if the destination file already exists. Do not
    overwrite — collisions almost certainly mean a bug.
  - Slug derived from SLUG-SOURCE when given, else from TITLE, via
    =org-roam-node-slugify= for parity with the capture template.
  - Timestamp prefix uses =current-time= at call site by default;
    callers passing CREATED-TIME override both the prefix and the
    drawer property so an imported note preserves its authored
    date end-to-end. The two timestamp shapes are formatted from
    the same internal time value via =format-time-string= — no
    string round-trips, no regex re-parsing.
  - =:CREATED:= property set to =[YYYY-MM-DD Day HH:MM]= matching
    the capture template's =%U= form.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--org-timestamp-of (time)
  "Return TIME as an inactive Org timestamp string,
matching the capture template's =%U= output (e.g. \"[2026-05-31 Sun 09:14]\").
TIME is an emacs internal time value (as produced by
`current-time', `encode-time', `parse-iso8601-time-string', etc.)."
  (format-time-string "[%Y-%m-%d %a %H:%M]" time))

(defun sns-roam--filename-prefix-of (time)
  "Return TIME as a 14-digit YYYYMMDDhhmmss filename prefix.
TIME is an emacs internal time value."
  (format-time-string "%Y%m%d%H%M%S" time))

(defun sns-roam--build-header-properties (id created kind aliases)
  "Return the list of =node-property= elements for a roam header.
ALIASES is a list of strings; when non-empty an extra
=ROAM_ALIASES= property is appended."
  (let ((base (list (org-ml-build-node-property "ID" id)
                    (org-ml-build-node-property "CREATED" created)
                    (org-ml-build-node-property "KIND" kind))))
    (if aliases
        (append base
                (list (org-ml-build-node-property
                       "ROAM_ALIASES"
                       (mapconcat (lambda (a) (format "\"%s\"" a))
                                  aliases " "))))
      base)))

(defun sns-roam--registered-file (id)
  "Return the file the org-roam database holds for node ID, or nil.
Resolves through `org-roam-node-from-id', as the edit primitives do."
  (let ((node (org-roam-node-from-id id)))
    (when node
      (org-roam-node-file node))))

(defun sns-roam--separate-body-elements (elements)
  "Return ELEMENTS with a blank line after each one but the last.
`org-ml-build-paragraph' gives a paragraph a :post-blank of 0, so
built paragraphs written in a row share no blank line and org reads
them as one paragraph. An element that already asks for more blank
lines keeps them. The last element is left alone, so no blank line
appears before the first headline, as `sns-roam-set-body' writes it."
  (append (mapcar (lambda (element)
                    (org-ml-set-property
                     :post-blank
                     (max 1 (org-ml-get-property :post-blank element))
                     element))
                  (butlast elements))
          (last elements)))

(defun sns-roam-create-node (title kind &optional elements id aliases created-time slug-source)
  "Create a new roam node with TITLE and KIND, returning a plist.

Slugifies TITLE for the filename, writes the file under
`org-roam-directory' with the standard roam header (:ID,
:CREATED, :KIND, optional :ROAM_ALIASES:, #+title) followed by
ELEMENTS — a list of org-ml AST nodes forming the body. ID, if
nil, is freshly generated via `org-id-new'. ALIASES is an
optional list of strings; when non-empty written as
:ROAM_ALIASES: per org-roam convention. CREATED-TIME, if
non-nil, is an emacs internal time value used in place of
`current-time' for both the :CREATED: property and the
filename's 14-digit prefix; both outputs are formatted from the
same time value. SLUG-SOURCE, if non-nil, is slugified for the
filename in place of TITLE — use it to decouple the filename slug
from a title that carries extra detail (e.g. an appended date),
so the file stays cleanly named while the title remains human.
Indexes the new file in the org-roam database, so the edit
primitives can resolve the returned ID at once.
Returns (:id :title :file). Errors before writing anything if the
destination exists or the database holds ID for another file.
Errors after indexing if ID does not resolve to the new file."
  (let* ((id       (or id (org-id-new)))
         (slug     (org-roam-node-slugify (or slug-source title)))
         (prefix   (sns-roam--filename-prefix-of created-time))
         (filename (concat prefix "-" slug ".org"))
         (path     (expand-file-name filename org-roam-directory))
         (created  (sns-roam--org-timestamp-of created-time))
         (props    (sns-roam--build-header-properties id created kind aliases))
         (drawer   (apply #'org-ml-build-property-drawer props))
         (kw       (org-ml-build-keyword "title" title))
         ;; Split ELEMENTS into the leading paragraph-ish section
         ;; children (which co-exist with drawer + keyword in a single
         ;; section) and the trailing headlines (which sit as siblings).
         (split-pos (or (cl-position-if
                         (lambda (e) (eq (org-ml-get-type e) 'headline))
                         elements)
                        (length elements)))
         (section-children (sns-roam--separate-body-elements
                            (cl-subseq elements 0 split-pos)))
         (sibling-headlines (cl-subseq elements split-pos))
         (section  (apply #'org-ml-build-section
                          (append (list drawer kw) section-children)))
         (content  (mapconcat #'org-ml-to-string
                              (cons section sibling-headlines)
                              "")))
    (when (file-exists-p path)
      (error "sns-roam: refusing to overwrite existing file %s" path))
    ;; org-roam only warns when it indexes a node whose ID another
    ;; file already holds, and the ID keeps resolving to that file.
    ;; Refuse before writing, so a retried batch that reuses a
    ;; pre-minted ID cannot leave a second file claiming it.
    (let ((registered (sns-roam--registered-file id)))
      (when registered
        (error "sns-roam: id %S already names %s, refusing to create %s"
               id registered path)))
    (with-temp-buffer
      (insert content)
      (write-region (point-min) (point-max) path nil 'silent))
    ;; The edit primitives look IDs up in the database, so a node
    ;; that is only on disk is unknown to them until it is indexed.
    (org-roam-db-update-file path)
    ;; Indexing reports some failures only as warnings, so check that
    ;; the ID now resolves to the new file before reporting success.
    (let ((registered (sns-roam--registered-file id)))
      (unless (and registered (file-equal-p registered path))
        (error "sns-roam: id %S resolves to %s after indexing, not to %s"
               id registered path)))
    (list :id id :title title :file path)))
#+end_src

** Discipline notes

- *No backdating.* If we ever need to import existing notes with
  preserved creation times, that's =sns-roam-import-node= with
  =:created= and =:filename-prefix= keyword args. Resist
  conflating it with =create-node= — different intent, different
  failure modes.
- *AST in, file out.* The whole point of choosing org over text
  formats is that the AST is the substrate. Callers hand over
  pre-built =org-ml-build-*= nodes; the function builds the
  header AST itself and hands the union to =org-ml-to-string=.
  No string templating in the body. Callers with a string of
  pre-formatted org (the importer, fed by pandoc) parse via
  =org-ml-parse-this-buffer= and pass the parsed children — see
  the importer for the canonical pattern.
- *Section vs sibling-headline split.* The =:PROPERTIES:= drawer
  and =#+title:= keyword live inside the file's leading
  =section= element. Body paragraphs and lists belong in that
  same section. Top-level headlines (=*=) are siblings, not
  children. The function sorts ELEMENTS into those two buckets
  on the assumption that paragraphs precede the first headline —
  if a caller intersperses paragraphs after a headline, those
  paragraphs become children of that headline (not the leading
  section), which is what org's structure says they should be
  anyway.
- *Caller passes KIND as a string.* No enum, no validation. The
  taxonomy lives in the user's head, and a single typo in the
  value should be visible in the file rather than rejected at
  the API.

* Create: a dated meeting note

Create a fresh =fleeting= node for one occurrence of a recurring
meeting and open it for editing. Interactive: =M-x
sns-roam-meeting-note= prompts for the series name.

** Contract

- *Input*: =SERIES= (string), the stable series name, such as
  "alan-smithee-1-1", "pir-prep" or "incident-review". It is trimmed,
  and an empty name is an error.
- *Output*: the =sns-roam-create-node= plist =(:id :title :file)=.
- *Side effects*: the new file is written through
  =sns-roam-create-node= and then visited.
- *Discipline*:
  - The title is SERIES with today's ISO date appended, so each
    occurrence is a distinct node in the node-find picker.
  - The filename slug derives from the bare SERIES, so the file is
    not double-dated. Org-roam already supplies the timestamp prefix.
  - KIND is "fleeting": raw meeting capture, to be mined into
    permanent notes later.
  - It always creates a fresh instance and never finds an existing
    node, so identical series names never collide.

** Implementation

#+begin_src emacs-lisp
(defun sns-roam--meeting-title (series time)
  "Return the title for a meeting-note instance of SERIES at TIME.
Appends an ISO date so instances are distinguishable in the
node-find picker while sharing a series name. Pure."
  (format "%s %s" series (format-time-string "%Y-%m-%d" time)))

(defun sns-roam-meeting-note (series)
  "Create a dated note instance for a recurring meeting SERIES.

SERIES is the stable series name (e.g. \"alan-smithee-1-1\",
\"pir-prep\", \"incident-review\"). The new node's title is
SERIES with today's date appended (\"alan-smithee-1-1 2026-06-16\")
so each occurrence is a distinct, picker-distinguishable node;
the filename slug derives from the bare SERIES, so the file is
not double-dated (org already supplies the timestamp prefix).
KIND is \"fleeting\" — raw meeting capture, to be mined into
permanent notes later. Always creates a fresh instance — never
finds an existing node — so identical series names never
collide. Opens the new file for editing.

Returns the create plist (:id :title :file)."
  (interactive
   (list (read-string "Recurring meeting series (e.g. alan-smithee-1-1): ")))
  (let* ((trimmed (string-trim series)))
    (when (string-empty-p trimmed)
      (error "sns-roam-meeting-note: empty series name"))
    (let* ((now    (current-time))
           (title  (sns-roam--meeting-title trimmed now))
           (result (sns-roam-create-node title "fleeting" nil nil nil now trimmed)))
      (find-file (plist-get result :file))
      result)))
#+end_src
